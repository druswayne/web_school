# Школьные курсы математики (7–9 классы)

Веб-приложение: несколько курсов алгебры и геометрии. Ученик видит только открытые учителем курсы; внутри курса занятия открываются по мере прохождения.

## Стек

- Flask 3
- SQLAlchemy + **SQLite** (по умолчанию)
- Переход на **PostgreSQL**: достаточно сменить `DATABASE_URL`
- Проверка фото решений: OpenRouter / OpenAI-compatible vision (как в `web/`)

Материалы лежат в `school_courses_out/` внутри этого проекта (алгебра и геометрия 7–9). При необходимости путь можно задать через `SCHOOL_COURSES_DIR`.

## Запуск

Из папки `web_school_courses_out/` (или из корня репозитория, если зависимости уже стоят):

```bash
pip install -r web_school_courses_out/requirements.txt
python web_school_courses_out/run.py
```

Откройте http://127.0.0.1:5001

При первом запуске создаются:

| Роль | Логин | Пароль |
|------|--------|--------|
| Администратор | `admin` | `changeme` |
| Демо-ученик | `ivan` | `ivan123` (все курсы и занятия открыты) |

Смените пароль администратора через переменные окружения. Файл `web_school_courses_out/.env` можно скопировать с `.env.example`. Ключ ИИ можно оставить в `.env` корня проекта (`OPENROUTER_API_KEY`).

## Как устроен курс

1. Администратор открывает ученику нужные **курсы**. Закрытые курсы в кабинете не показываются.
2. В открытом курсе сразу доступно **занятие 1**. Следующие открываются после практической части (80% на одном уровне) или администратором.
3. **Теория** — страница с прогресс-баром. Дочитывание до конца открывает тест.
4. **Тест** — 80%. Попытки сохраняются. Ученик видит, какие задания неверны, но не видит ключ.
5. **Практика** — ученик сам выбирает уровень (1–2 … 9–10) в модалке. Можно переключаться между уровнями. Зачёт — 80% верных заданий **на одном** уровне, не суммарно.
6. Практику решают в тетради, фотографируют, ИИ проверяет решение.

На плитке курса и занятия показываются уровень прохождения и успешность попыток. Учитель в карточке ученика видит, какого уровня задачи решались.

## Редактор материалов

В разделе «Курсы» администратор правит теорию, тест и практику занятия. Практика сохраняется в кэш уровня и в файл занятия.

## PostgreSQL

В `.env`:

```
DATABASE_URL=postgresql+psycopg2://user:password@localhost:5432/school_math
```

Таблицы создаются при старте приложения (`db.create_all()`).
