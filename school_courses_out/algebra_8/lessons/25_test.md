# Тест по теории. Занятие 25. Свойства и график функции y = x^3

**Заданий:** 10  
**Формат:** 4 варианта ответа (а–г). Верных может быть один или несколько. Если в условии сказано «Выберите все верные ответы» — отметьте все подходящие; иначе верный один.

Тест проверяет определения, формулы и правила теории этого занятия.

## Т1. *(Область определения)*

Какова область определения функции $y=x^{3}$?

а) Только положительные действительные числа
б) Все действительные числа
в) Все неотрицательные действительные числа
г) Все действительные числа, кроме нуля

## Т2. *(Множество значений)*

а) $E=[0;+\infty)$
б) $E=(-\infty;0]$
в) $E=\mathbb{R}$
г) $E=(0;+\infty)$

а) $x=-1$
б) $x=0$
в) $x=1$
г) Нулей нет

а) При $x>0$
б) При $x\geq 0$
в) При $x\in(0;+\infty)$
г) При $x\in(-\infty;0)$

Выберите все верные утверждения о знаке значения функции $y=x^{3}$.

а) При $x<0$ значение $x^{3}$ отрицательно
б) При $x=0$ значение $x^{3}$ равно нулю
в) При $x>0$ значение $x^{3}$ отрицательно
г) Куб любого действительного числа неотрицателен

а) Линейная функция

в) Кубическая парабола
г) Гипербола

а) Плавной линией

## Т8. *(Монотонность)*

а) Функция возрастает на всей числовой прямой

г) Если $x_{1}<x_{2}$, то $x_{1}^{3}>x_{2}^{3}$

в) $(-m;-n)$
