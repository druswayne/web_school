# Тест по теории. Занятие 2. Множество иррациональных чисел. Множество действительных чисел

**Заданий:** 10  
**Формат:** 4 варианта ответа (а–г). Верных может быть один или несколько. Если в условии сказано «Выберите все верные ответы» — отметьте все подходящие; иначе верный один.

Тест проверяет определения, формулы и правила теории этого занятия.

## Т1. *(Рациональные числа)*

Какое определение рационального числа является верным?

а) Число, которое можно представить в виде дроби $\frac{m}{n}$, где $m$ — целое, а $n$ — натуральное.
б) Только целое положительное число.
в) Бесконечная непериодическая десятичная дробь.
г) Любое число, записанное с помощью квадратного корня.

## Т2. *(Десятичная запись)*

Какие десятичные записи могут соответствовать рациональному числу? Выберите все верные ответы.

а) Конечная десятичная дробь.
б) Бесконечная периодическая десятичная дробь.
в) Бесконечная непериодическая десятичная дробь.
г) Только целое число без десятичной части.

## Т3. *(Иррациональные числа)*

Какое определение иррационального числа является верным?

а) Число, которое можно представить в виде $\frac{m}{n}$, где $m$ — целое, а $n$ — натуральное.
б) Бесконечная непериодическая десятичная дробь.
в) Любая бесконечная десятичная дробь.
г) Любое число, не являющееся натуральным.

## Т4. *(Квадратный корень)*

Какие из чисел являются иррациональными? Выберите все верные ответы.

а) $\sqrt{2}$
б) $\sqrt{9}$
в) $\sqrt{15}$
г) $\pi$

## Т5. *(Множество действительных чисел)*

Что называют множеством действительных чисел?

а) Только множество рациональных чисел.
б) Только множество иррациональных чисел.
в) Объединение множеств рациональных и иррациональных чисел.
г) Множество только целых чисел.

## Т6. *(Вложенность множеств)*

Какая цепочка вложенности множеств является верной?

а) $R \subset Q \subset Z \subset N$
б) $N \subset Z \subset Q \subset R$
в) $N \subset Q \subset Z \subset R$
г) $Z \subset N \subset Q \subset R$

## Т7. *(Рациональные и иррациональные числа)*

Какие утверждения являются верными? Выберите все верные ответы.

а) $Q \cap I = \varnothing$.
б) Каждое действительное число является рациональным.
в) $I \subset R$.
г) Если число принадлежит $R$, то оно обязательно принадлежит $Z$.

## Т8. *(Периодические дроби)*

Какое утверждение о бесконечной периодической десятичной дроби является верным?

а) Она всегда иррациональна.
б) Она является рациональным числом.
в) Она не является действительным числом.
г) Она обязательно является целым числом.

## Т9. *(Оценка квадратного корня)*

Какое правило позволяет получить оценку квадратного корня при $a \geq 0$?

а) Если $a^{2} < x < b^{2}$, то $a < \sqrt{x} < b$.
б) Если $a^{2} < x < b^{2}$, то $\sqrt{x} < a$.
в) Если $a^{2} < x < b^{2}$, то $\sqrt{x} > b$.
г) Если $a^{2} < x < b^{2}$, то $\sqrt{x} = a + b$.

## Т10. *(Сравнение иррациональных чисел)*

Как правильно сравнивать иррациональные числа по их десятичным приближениям?

а) Сравнивают только первые цифры после запятой.
б) Сначала сравнивают целые части, затем цифры по разрядам до первой различающейся цифры.
в) Сравнивают только количество цифр после запятой.
г) Иррациональные числа нельзя сравнивать.
