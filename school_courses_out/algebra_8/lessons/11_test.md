# Тест по теории. Занятие 11. Квадратные уравнения

**Заданий:** 10  
**Формат:** 4 варианта ответа (а–г). Верных может быть один или несколько. Если в условии сказано «Выберите все верные ответы» — отметьте все подходящие; иначе верный один.

Тест проверяет определения, формулы и правила теории этого занятия.

## Т1. *(Стандартный вид)*

Какой вид имеет квадратное уравнение?

а) $ax+b=0$, где $a\neq 0$
б) $ax^{2}+bx+c=0$, где $a\neq 0$
в) $ax^{2}+c=0$, где $b\neq 0$
г) $ax^{3}+bx^{2}+c=0$, где $a\neq 0$

## Т2. *(Коэффициенты)*

Выберите все верные ответы. Какие утверждения о коэффициентах квадратного уравнения $ax^{2}+bx+c=0$ верны?

а) $a$ — коэффициент при $x^{2}$
б) $b$ — свободный член
в) $c$ — свободный член
г) $a$ не может быть равным нулю

## Т3. *(Дискриминант)*

Какая формула используется для вычисления дискриминанта квадратного уравнения $ax^{2}+bx+c=0$?

а) $D=b^{2}+4ac$
б) $D=b^{2}-4ac$
в) $D=4ac-b^{2}$
г) $D=b^{2}-2ac$

## Т4. *(Число корней)*

Выберите все верные ответы. Как связано значение дискриминанта с числом корней квадратного уравнения?

а) При $D>0$ уравнение имеет два корня
б) При $D=0$ уравнение имеет один корень
в) При $D<0$ уравнение имеет один корень
г) При $D<0$ уравнение не имеет корней

## Т5. *(Формула корней)*

Какая формула предназначена для нахождения корней квадратного уравнения при $D>0$?

а) $x_{1}=\frac{-b-\sqrt{D}}{2a}$, $x_{2}=\frac{-b+\sqrt{D}}{2a}$
б) $x_{1}=\frac{b-\sqrt{D}}{2a}$, $x_{2}=\frac{b+\sqrt{D}}{2a}$
в) $x_{1}=\frac{-b-\sqrt{D}}{2b}$, $x_{2}=\frac{-b+\sqrt{D}}{2b}$
г) $x_{1}=\frac{b-\sqrt{D}}{a}$, $x_{2}=\frac{b+\sqrt{D}}{a}$

## Т6. *(Нулевой дискриминант)*

Какая формула используется для нахождения единственного корня квадратного уравнения при $D=0$?

а) $x=-\frac{b}{a}$
б) $x=\frac{b}{2a}$
в) $x=-\frac{b}{2a}$
г) $x=-\frac{b}{2c}$

## Т7. *(Приведение к стандартному виду)*

Выберите все верные действия при приведении уравнения к виду $ax^{2}+bx+c=0$.

а) Раскрыть скобки
б) Перенести все слагаемые в одну часть уравнения
в) При переносе слагаемого через знак равенства сохранить его знак
г) Привести подобные слагаемые

## Т8. *(Полный квадрат)*

Выберите все верные утверждения о формуле квадрата разности.

а) $(a-b)^{2}=a^{2}-2ab+b^{2}$
б) $(a-b)^{2}=a^{2}-b^{2}$
в) Средний член квадрата разности равен $-2ab$
г) В разложении квадрата разности отсутствует последний квадрат

## Т9. *(Параметр)*

Выберите все верные условия для уравнения $ax^{2}+bx+c=0$ с параметрами.

а) Чтобы уравнение оставалось квадратным, необходимо $a\neq 0$
б) Чтобы уравнение имело два корня, необходимо $D>0$
в) Чтобы уравнение имело один корень, необходимо $D<0$
г) Чтобы уравнение не имело корней, необходимо $D<0$

## Т10. *(Знаки и преобразования)*

Выберите все верные правила решения квадратных уравнений.

а) Перед вычислением дискриминанта уравнение приводят к стандартному виду
б) При переносе слагаемого через знак равенства его знак меняется
в) При вычислении $b^{2}$ знак коэффициента $b$ можно не учитывать
