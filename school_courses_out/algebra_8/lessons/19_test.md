# Тест по теории. Занятие 19. Монотонность, промежутки знакопостоянства квадратичной функции

**Заданий:** 10  
**Формат:** 4 варианта ответа (а–г). Верных может быть один или несколько. Если в условии сказано «Выберите все верные ответы» — отметьте все подходящие; иначе верный один.

Тест проверяет определения, формулы и правила теории этого занятия.

## Т1. *(Определение возрастания)*

Какое утверждение является определением возрастающей функции на промежутке?

а) Большему значению аргумента соответствует меньшее значение функции.
б) Для любых двух значений аргумента большему значению аргумента соответствует большее значение функции.
в) Функция принимает только положительные значения.
г) График функции пересекает ось ординат.

## Т2. *(Абсцисса вершины)*

Выберите все верные ответы. Для квадратичной функции $y=ax^{2}+bx+c$, где $a\neq 0$, абсцисса вершины параболы определяется формулой:

а) $x_{в}=-\frac{b}{2a}$
б) $x_{в}=\frac{b}{2a}$
в) $x_{в}=-\frac{b}{a}$
г) $x_{в}=-\frac{1}{2}\cdot\frac{b}{a}$

## Т3. *(Монотонность при a > 0)*

Для квадратичной функции с положительным первым коэффициентом $a>0$ укажите верные промежутки монотонности. Выберите все верные ответы.

а) Функция убывает на промежутке $(-\infty; x_{в}]$.
б) Функция возрастает на промежутке $[x_{в}; +\infty)$.
в) Функция возрастает на промежутке $(-\infty; x_{в}]$.
г) Функция убывает на промежутке $[x_{в}; +\infty)$.

## Т4. *(Монотонность при a < 0)*

Для квадратичной функции с отрицательным первым коэффициентом $a<0$ укажите верные промежутки монотонности. Выберите все верные ответы.

а) Функция возрастает на промежутке $(-\infty; x_{в}]$.
б) Функция убывает на промежутке $[x_{в}; +\infty)$.
в) Функция убывает на промежутке $(-\infty; x_{в}]$.
г) Функция возрастает на промежутке $[x_{в}; +\infty)$.

## Т5. *(Вершинная форма)*

Как определяется абсцисса вершины функции $y=a(x-p)^{2}+q$?

а) $x_{в}=q$
б) $x_{в}=-p$
в) $x_{в}=p$
г) $x_{в}=a$

## Т6. *(Промежутки монотонности)*

Что называют промежутками монотонности функции?

а) Промежутки, на которых функция принимает нулевые значения.
б) Промежутки возрастания и убывания функции.
в) Промежутки, на которых график расположен выше оси $Ox$.
г) Промежутки, на которых аргумент принимает только положительные значения.

## Т7. *(Сравнение значений)*

Выберите все верные утверждения о сравнении значений функции по значениям аргумента.

а) На промежутке возрастания из $x_{1}<x_{2}$ следует $f(x_{1})<f(x_{2})$.
б) На промежутке убывания из $x_{1}<x_{2}$ следует $f(x_{1})>f(x_{2})$.
в) Для любых двух аргументов квадратичной функции всегда можно сравнить значения без вычислений.
г) Если аргументы находятся по разные стороны от вершины, сравнение значений только по порядку аргументов может быть невозможным.

## Т8. *(Знак функции)*

Выберите все верные утверждения о знаке значения функции.

а) Если график расположен выше оси $Ox$, то значение функции положительно.
б) Если график расположен ниже оси $Ox$, то значение функции отрицательно.
в) В точках пересечения графика с осью $Ox$ функция принимает положительные значения.
г) На оси $Ox$ значение функции равно нулю.

## Т9. *(Знакопостоянство при двух корнях)*

Квадратичная функция имеет два различных корня $x_{1}<x_{2}$. Как распределяются знаки функции при $a>0$?

а) Функция положительна между корнями и отрицательна вне корней.
б) Функция отрицательна между корнями и положительна вне корней.
в) Функция положительна на всей числовой прямой.
г) Функция отрицательна на всей числовой прямой.

## Т10. *(Границы промежутков знакопостоянства)*

Как записываются промежутки, на которых квадратичная функция принимает строго положительные или строго отрицательные значения, если на границах она равна нулю?

а) С использованием квадратных скобок, так как корни входят в промежутки.
б) С использованием круглых скобок, так как корни не входят в промежутки строгого неравенства.
в) С использованием только квадратных скобок для положительных значений.
г) Границы промежутков всегда не указываются.
