# Тест по теории. Занятие 9. Квадратные уравнения. Решение неполных квадратных уравнений

**Заданий:** 10  
**Формат:** 4 варианта ответа (а–г). Верных может быть один или несколько. Если в условии сказано «Выберите все верные ответы» — отметьте все подходящие; иначе верный один.

Тест проверяет определения, формулы и правила теории этого занятия.

## Т1. *(Определение квадратного уравнения)*

Какое уравнение является квадратным?

а) $3x + 5 = 0$
б) $2x^{2} - 7x + 1 = 0$
в) $x^{3} - 4 = 0$
г) $5x^{4} + x = 0$

## Т2. *(Коэффициенты квадратного уравнения)*

Выберите все верные ответы. Для уравнения $-6x^{2} + 4x - 9 = 0$ укажите его коэффициенты.

а) $a = -6$
б) $b = 4$
в) $c = 9$
г) $c = -9$

## Т3. *(Отсутствующие коэффициенты)*

Какие значения коэффициентов имеет уравнение $x^{2} - 8 = 0$?

а) $a = 1, b = -8, c = 0$
б) $a = 1, b = 0, c = -8$
в) $a = 0, b = 1, c = -8$
г) $a = 1, b = 8, c = 0$

## Т4. *(Виды неполных уравнений)*

Выберите все верные ответы. Какие условия соответствуют неполному квадратному уравнению?

а) $b = 0$
б) $c = 0$
в) $a = 0$
г) $b = 0$ и $c = 0$

## Т5. *(Уравнение с общим множителем)*

Какое действие является первым при решении уравнения вида $ax^{2} + bx = 0$?

а) Разделить обе части уравнения на $x$
б) Вынести $x$ за скобки
в) Сложить коэффициенты $a$ и $b$
г) Перенести $bx$ в правую часть и извлечь квадратный корень

## Т6. *(Свойство произведения)*

Выберите все верные формулировки свойства произведения, равного нулю.

а) Если произведение равно нулю, то хотя бы один множитель равен нулю
б) Если один из множителей равен нулю, то произведение равно нулю
в) Произведение равно нулю только тогда, когда все множители равны нулю
г) Для произведения $ab = 0$ верно: $a = 0$ или $b = 0$

## Т7. *(Разность квадратов)*

Какая формула является формулой разности квадратов?

а) $u^{2} - v^{2} = (u - v)(u + v)$
б) $u^{2} - v^{2} = (u - v)^{2}$
в) $u^{2} - v^{2} = (u + v)^{2}$
г) $u^{2} - v^{2} = u^{2} + v^{2}$

## Т8. *(Корни уравнения $x^{2} = k$)*

Выберите все верные утверждения о действительных корнях уравнения $x^{2} = k$.

а) При $k > 0$ уравнение имеет два корня: $x = \sqrt{k}$ и $x = -\sqrt{k}$
б) При $k = 0$ уравнение имеет единственный корень $x = 0$
в) При $k < 0$ уравнение имеет два действительных корня
г) При $k < 0$ уравнение не имеет действительных корней

## Т9. *(Уравнение $ax^{2} = 0$)*

Какое утверждение верно для уравнения $ax^{2} = 0$, если $a \neq 0$?

а) Оно имеет два корня: $x = a$ и $x = -a$
б) Оно имеет единственный корень $x = 0$
в) Оно не имеет действительных корней
г) Его нельзя решать делением на $a$

## Т10. *(Отбор корней по смыслу)*

Какое правило применяют при решении текстовой задачи, если неизвестная величина обозначает длину, массу или время?

а) Всегда выбирают отрицательный корень
б) Оставляют все найденные корни без проверки
в) Отрицательный корень обычно не подходит по смыслу
г) Можно заменить отрицательный корень на положительный без проверки
