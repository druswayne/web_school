# Тест по теории. Занятие 3. Действительные числа

**Заданий:** 10  
**Формат:** 4 варианта ответа (а–г). Верных может быть один или несколько. Если в условии сказано «Выберите все верные ответы» — отметьте все подходящие; иначе верный один.

Тест проверяет определения, формулы и правила теории этого занятия.

## Т1. *(Включения множеств)*

Какая цепочка включений множеств является верной?

а) R ⊂ Q ⊂ Z ⊂ N
б) N ⊂ Z ⊂ Q ⊂ R
в) N ⊂ Q ⊂ Z ⊂ R
г) Z ⊂ N ⊂ Q ⊂ R

## Т2. *(Рациональные числа)*

Выберите все верные ответы. Какие утверждения о рациональных числах верны?

а) Рациональное число можно представить в виде дроби m/n, где m ∈ Z, n ∈ N.
б) Рациональная десятичная дробь может быть только конечной.
в) Любое целое число является рациональным.
г) Отрицательное число не может быть рациональным.

## Т3. *(Иррациональные числа)*

Какое определение иррационального числа является верным?

а) Это любое отрицательное число.
б) Это бесконечная периодическая десятичная дробь.
в) Это бесконечная непериодическая десятичная дробь.
г) Это любое число, не являющееся целым.

## Т4. *(Действительные числа)*

Выберите все верные ответы. Какие утверждения о множестве действительных чисел верны?

а) Множество действительных чисел обозначают буквой R.
б) R = Q ∪ I.
в) Иррациональные числа не являются действительными.
г) Любое действительное число обязательно является рациональным.

## Т5. *(Арифметический корень)*

Какое условие характеризует арифметический квадратный корень √a = b?

а) b < 0 и b² = a
б) b ≥ 0 и b² = a
в) b ≥ 0 и b² = −a
г) b² = a, при этом знак b не имеет значения

## Т6. *(Корень полного квадрата)*

Выберите все верные утверждения о квадратном корне.

а) √49 является рациональным числом.
б) √7 является иррациональным числом.
в) −√7 является рациональным числом, так как знак минус не влияет на тип числа.
г) √16 = −4.

## Т7. *(Положение корня)*

Какое утверждение используется для определения положения числа √m между последовательными неотрицательными целыми числами?

а) Если a² < m < b² и a ≥ 0, то a < √m < b.
б) Если a² < m < b², то всегда −b < √m < −a.
в) Если a < m < b, то a² < √m < b².
г) Если a² = m = b², то a < √m < b.

## Т8. *(Сравнение корней)*

Выберите все верные правила сравнения неотрицательных корней.

а) При a ≥ 0 и b ≥ 0: √a < √b тогда и только тогда, когда a < b.
б) При сравнении √a и числа b ≥ 0 можно сравнить a и b².
в) Из a < b всегда следует −√a < −√b.
г) Для сравнения неотрицательных корней нужно сравнивать только их знаки.

## Т9. *(Сравнение отрицательных чисел)*

Какое неравенство является верным?

а) −√10 > −√7
б) −√10 = −√7
в) −√10 < −√7
г) Сравнить −√10 и −√7 невозможно

## Т10. *(Оценка выражений)*

Выберите все верные правила оценки выражений.

а) Если a < x < b и k > 0, то ka < kx < kb.
б) При умножении неравенства на отрицательное число знак неравенства меняется.
в) Если a < x < b и k < 0, то ka < kx < kb.
г) Если a < x < b и c < y < d, то a + c < x + y < b + d.
