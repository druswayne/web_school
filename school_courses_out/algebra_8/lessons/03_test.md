# Тест по теории. Занятие 3. Действительные числа

**Заданий:** 10  
**Формат:** 4 варианта ответа (а–г). Верных может быть один или несколько. Если в условии сказано «Выберите все верные ответы» — отметьте все подходящие; иначе верный один.

Тест проверяет определения, формулы и правила теории этого занятия.

## Т1. *(числовые множества)*

Какое определение рационального числа является верным?

а) Рациональным называется любое положительное число.
б) Рациональным называется число, которое можно представить в виде отношения двух целых чисел, где знаменатель не равен нулю.
в) Рациональным называется только целое число.
г) Рациональным называется число, которое нельзя представить в виде дроби.

## Т2. *(обозначения множеств)*

Выберите все верные ответы. Какие обозначения соответствуют указанным числовым множествам?

а) $\mathbb{N}$ — множество натуральных чисел.
б) $\mathbb{Z}$ — множество рациональных чисел.
в) $\mathbb{Q}$ — множество рациональных чисел.
г) $\mathbb{R}$ — множество действительных чисел.

## Т3. *(взаимосвязь множеств)*

Какая цепочка включений числовых множеств является верной?

а) $\mathbb{N} \subset \mathbb{Z} \subset \mathbb{Q} \subset \mathbb{R}$
б) $\mathbb{R} \subset \mathbb{Q} \subset \mathbb{Z} \subset \mathbb{N}$
в) $\mathbb{Z} \subset \mathbb{N} \subset \mathbb{Q} \subset \mathbb{R}$
г) $\mathbb{Q} \subset \mathbb{R} \subset \mathbb{Z} \subset \mathbb{N}$

## Т4. *(иррациональные числа)*

Какое определение иррационального числа является верным?

а) Иррациональное число — это любое отрицательное число.
б) Иррациональное число — это число, которое можно представить в виде отношения двух целых чисел.
в) Иррациональное число — это действительное число, которое нельзя представить в виде отношения двух целых чисел.
г) Иррациональное число — это только число, меньшее нуля.

## Т5. *(десятичная запись)*

Выберите все верные ответы. Какие утверждения о рациональных числах справедливы?

а) Любое рациональное число имеет конечную или бесконечную периодическую десятичную запись.
б) Любая бесконечная десятичная дробь является рациональным числом.
в) Конечную десятичную дробь можно представить в виде обыкновенной дроби со знаменателем, равным степени десяти.
г) Бесконечная непериодическая десятичная дробь является рациональным числом.

## Т6. *(действительные числа)*

Какое утверждение о действительных числах является верным?

а) Множество действительных чисел состоит только из рациональных чисел.
б) Множество действительных чисел состоит из рациональных и иррациональных чисел.
в) Множество действительных чисел состоит только из натуральных чисел.
г) Действительными являются только числа, имеющие конечную десятичную запись.

## Т7. *(сравнение корней)*

Выберите все верные ответы. При каких условиях для неотрицательных чисел $a$ и $b$ справедливо сравнение $\sqrt{a} < \sqrt{b}$?

а) Если $a < b$.
б) Если $a^{2} < b^{2}$.
в) Если $a > b$.
г) Если $0 \leq a < b$.

## Т8. *(оценка выражений)*

Известно, что $a < x < b$ и $c < y < d$. Какое утверждение об оценке разности $x-y$ является верным?

а) Всегда $c-b < x-y < d-a$.
б) Всегда $a-d < x-y < b-c$.
в) Всегда $a-c < x-y < b-d$.
г) Всегда $a+c < x-y < b+d$.

## Т9. *(квадратный корень)*

Выберите все верные ответы. Какое свойство арифметического квадратного корня справедливо при $a \geq 0$?

а) $\sqrt{a} \geq 0$.
б) $(\sqrt{a})^{2} = a$.
в) $\sqrt{a^{2}} = a$ для любого действительного $a$.
г) $\sqrt{a}$ — это неотрицательное число, квадрат которого равен $a$.

## Т10. *(доказательство иррациональности)*

Как обычно доказывают иррациональность числа?

а) Предполагают, что число рационально, и получают противоречие.
б) Сравнивают число только с нулём.
в) Представляют число в виде конечной десятичной дроби без проверки.
г) Возводят число в квадрат и объявляют результат иррациональным.
