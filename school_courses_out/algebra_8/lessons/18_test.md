# Тест по теории. Занятие 18. Квадратичная функция и ее свойства

**Заданий:** 10  
**Формат:** 4 варианта ответа (а–г). Верных может быть один или несколько. Если в условии сказано «Выберите все верные ответы» — отметьте все подходящие; иначе верный один.

Тест проверяет определения, формулы и правила теории этого занятия.

## Т1. *(Определение)*

Какое условие является обязательным для функции вида $y=ax^{2}+bx+c$, чтобы она была квадратичной?

а) $a=0$
б) $a\neq 0$
в) $b\neq 0$
г) $c\neq 0$

## Т2. *(Направление ветвей)*

Выберите все верные ответы. От чего зависит направление ветвей параболы $y=ax^{2}+bx+c$?

а) От знака коэффициента $a$
б) При $a>0$ ветви направлены вверх
в) При $a<0$ ветви направлены вниз
г) От значения свободного члена $c$

## Т3. *(Формы записи)*

Какая запись является формой квадратичной функции в виде выделенного полного квадрата?

а) $y=ax^{2}+bx+c$
б) $y=a(x-x_{1})(x-x_{2})$
в) $y=a(x-m)^{2}+n$
г) $y=a(x+m)^{2}-n$

## Т4. *(Абсцисса вершины)*

Какая формула используется для нахождения абсциссы вершины параболы $y=ax^{2}+bx+c$?

а) $x_{B}=-\frac{b}{a}$
б) $x_{B}=-\frac{b}{2a}$
в) $x_{B}=\frac{b}{2a}$
г) $x_{B}=-\frac{b^{2}}{4a}$

## Т5. *(Область определения)*

Какова область определения любой квадратичной функции $y=ax^{2}+bx+c$, где $a\neq 0$?

а) $D=[0;+\infty)$
б) $D=(-\infty;0]$
в) $D=\mathbb{R}$
г) $D=[-1;1]$

## Т6. *(Множество значений)*

Выберите все верные ответы. Как записывается множество значений квадратичной функции с вершиной $(x_{B};y_{B})$?

а) При $a>0$: $E=[y_{B};+\infty)$
б) При $a<0$: $E=(-\infty;y_{B}]$
в) При $a>0$: $E=(-\infty;y_{B}]$
г) При $a<0$: $E=[y_{B};+\infty)$

## Т7. *(Ось симметрии)*

Как задаётся ось симметрии параболы $y=ax^{2}+bx+c$?

а) $y=x_{B}$
б) $x=y_{B}$
в) $x=x_{B}$
г) $y=y_{B}$

## Т8. *(Нули функции)*

Выберите все верные ответы. Что называют нулями квадратичной функции?

а) Значения $x$, при которых $y=0$
б) Корни уравнения $ax^{2}+bx+c=0$
в) Абсциссы точек пересечения графика с осью $Ox$
г) Ординаты точек пересечения графика с осью $Oy$

## Т9. *(Дискриминант и нули)*

Как количество действительных нулей квадратичной функции связано со знаком дискриминанта $D$?

а) При $D>0$ — два нуля, при $D=0$ — один нуль, при $D<0$ — нулей нет
б) При $D>0$ — один нуль, при $D=0$ — два нуля, при $D<0$ — нулей нет
в) При любом $D$ функция имеет два нуля
г) При $D<0$ — один нуль, при $D=0$ — нулей нет

## Т10. *(Пересечение с осями)*

Выберите все верные ответы. Какое условие используется для нахождения точек пересечения графика квадратичной функции с координатными осями?

а) Для пересечения с осью $Ox$ полагают $y=0$
б) Для пересечения с осью $Oy$ полагают $x=0$
в) Точки на оси $Ox$ имеют вид $(x;0)$
г) Точки на оси $Oy$ имеют вид $(x;0)$
