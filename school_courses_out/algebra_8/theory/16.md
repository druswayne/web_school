# § §12. Решение целых рациональных уравнений, сводящихся к квадратным уравнениям

**Страницы учебника:** 147–150
**Глава:** Квадратные уравнения

## Определения
### Определение. Биквадратное уравнение
Уравнение вида $ax^4 + bx^2 + c = 0$, где $a \ne 0$, называется биквадратным.

### Определение. Целые рациональные уравнения
Целыми рациональными уравнениями называются уравнения, у которых в левой и правой частях — только многочлены.

## Правила и алгоритмы
### Решение уравнений методом замены переменной
1. Ввести новую переменную, обозначив ею повторяющееся выражение.
2. Решить полученное уравнение относительно новой переменной.
3. Подставить найденные значения новой переменной в выражение для исходной переменной и решить полученные уравнения.
4. Записать все найденные значения исходной переменной в ответ.

## Ключевые разобранные задания учебника
### Пример на странице 147
Решите уравнение $2x^4 + 15x^2 - 8 = 0$.
Показывает применение метода замены переменной для решения биквадратного уравнения.

### Пример 1 на странице 148
Решите уравнение $(x - 2)^2 - 5(x - 2) + 6 = 0$.
Показывает два способа решения: раскрытие скобок и приведение к квадратному уравнению, а также метод замены переменной.

### Пример 2а на странице 149
Решите уравнение $2(x^2 - x)^2 - 5(x^2 - x) - 3 = 0$.
Показывает применение метода замены переменной для уравнения, где повторяющееся выражение является многочленом.

### Пример 2б на странице 149
Решите уравнение $4x^2 - 7|x| + 3 = 0$.
Показывает применение метода замены переменной для уравнения, содержащего модуль, используя свойство $x^2 = |x|^2$.
