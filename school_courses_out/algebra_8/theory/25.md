## Свойства
### Свойства функции $y = x^3$
1. Область определения функции. Так как выражение $x^3$ является степенью с натуральным показателем, то оно имеет смысл для любого действительного числа $x$, значит, областью определения функции $y = x^3$ являются все действительные числа: $D = \mathbb{R}$.
2. Множество значений функции. Степень $x^3$ может принимать положительные и отрицательные значения, быть равной нулю. Множеством значений функции $y = x^3$ является промежуток $(-\infty; +\infty)$: $E = \mathbb{R}$.
3. Нули функции. Так как $y = 0$, т. е. $x^3 = 0$, при $x = 0$, то это значение аргумента есть нуль функции.
4. Промежутки знакопостоянства функции. Функция принимает положительные значения $(y > 0)$, если $x \in (0; +\infty)$. Функция принимает отрицательные значения $(y < 0)$, если $x \in (-\infty; 0)$.
5. График функции $y = x^3$. Для построения графика функции $y = x^3$ составим таблицу значений функции, соответствующих некоторым значениям аргумента.

| $x$ | -2 | -1 | 0 | 1 | 2 |
|---|---|---|---|---|---|
| $y$ | -8 | -1 | 0 | 1 | 8 |

Соединим точки плавной линией, получим график функции $y = x^3$ (рис. 100). Эта линия называется *кубической параболой*.
6. Промежутки монотонности функции. С увеличением значений аргумента значения функции увеличиваются, т. е. функция возрастает на промежутке $(-\infty; +\infty)$.
7. Точки графика функции $y = x^3$ симметричны относительно точки $(0; 0)$.

## Ключевые разобранные задания учебника
### 1. Найдите значения функции $y = x^3$, если: а) $x = 0,02$; б) $x = -0,02$; в) $x = 1,2$; г) $x = -1,2$.
Показывает вычисление значений функции $y=x^3$ для заданных значений аргумента.

### 2. Функция задана формулой $f(x) = x^3$. Сравните: а) $f(2,356)$ и $f(2,365)$; б) $f(-4,006)$ и $f(-4,0006)$.
Показывает применение свойства возрастания функции $f(x) = x^3$ на всей области определения для сравнения значений функции.

### 3. Принадлежит ли графику функции $y = x^3$ точка с координатами: а) $(1; 0)$; б) $(1; 1)$; в) $(1; -1)$; г) $(-1; -1)$?
Показывает, как проверить принадлежность точки графику функции, подставляя её координаты в уравнение функции.

### 4. Точка $M(m; n)$ принадлежит графику функции $y = x^3$. Какая из точек также принадлежит этому графику: а) $N(-m; n)$; б) $K(m; -n)$; в) $L(-m; -n)$?
Показывает применение свойства симметрии графика функции $y = x^3$ относительно начала координат.

## Упражнения параграфа

4.49. Функция задана формулой $f(x) = x^3$. Найдите значение аргумента, при котором значение функции равно $1$; $0$; $-8$; $2\sqrt{2}$.
4.50. Выберите точки, через которые проходит график функции $y = x^3$: а) $A(-5; -125)$; б) $B(4; -64)$; в) $C(10; 100)$; г) $D(-0,1; -0,001)$; д) $E(2; 6)$; е) $M(\sqrt{3}; 3\sqrt{3})$. Запишите координаты еще каких-либо двух точек, принадлежащих графику функции $y = x^3$.
4.51. Функция задана формулой $f(x) = x^3$. Сравните: а) $f(2,1)$ и $f(3,9)$; б) $f(-8,97)$ и $f(-9,52)$; в) $f(-\sqrt{5})$ и $f(-2)$; г) $f(2\sqrt{3})$ и $f(13)$.
4.52. Дана функция $g(x) = x^3$. Расположите в порядке убывания $g(-2,8)$; $g(0)$; $g(-4,65)$ и $g(15)$.
4.53. В одной системе координат постройте графики функций и найдите координаты их общих точек: а) $y = x^3$ и $y = 2 - x$; б) $y = x^3$ и $y = \frac{16}{x}$.
4.54. Функция задана формулой $f(x) = x^3$. Найдите значение выражения: а) $f(-3) + f(3) - f(5)$; б) $f(2,45) + f(-2,45) + f(0)$; в) $f(-\sqrt{7}) + f(\sqrt{7})$; г) $f(\sqrt{2}) + f(-\sqrt{2}) + f(-1)$. Обобщите полученные результаты. Для функции $f(x) = x^3$ найдите $f(a) + f(-a) + f(1)$, где $a$ — любое действительное число.
4.55. В одной системе координат постройте графики функций $y = x^3$ и $y = x$. Сравните свойства функций $y = x^3$ и $y = x$.
4.56. Найдите значения функции $y = x^3$ при значениях аргумента, равных $1$; $-3$; $0,1$; $-2,5$.
4.57. Для функции $f(x) = x^3$ найдите значение аргумента, при котором $f(x) = -1$; $f(x) = 27$; $f(x) = -125$; $f(x) = 7\sqrt{7}$.
