## Упражнения параграфа
3.163. Найдите значения переменной, при которых:
а) значения квадрата двучлена $x + 1$ меньше значений квадрата двучлена $2x - 1$;
б) значения квадрата двучлена $3x - 5$ не превосходят значений квадрата двучлена $x + 7$.
3.164. Докажите, что при всех значениях переменной верно неравенство $-3x^2 + x < \frac{1}{3}$.
3.165. Решите неравенство:
а) $\frac{x^2}{10} + 2 < \frac{9x}{10}$;
б) $\frac{x^2}{3} \ge \frac{3x+3}{4}$;
в) $\frac{x^2+2}{14} > \frac{x^2-23}{4}$;
г) $\frac{x^2}{3} - \frac{3x-5}{4} < \frac{2x}{3}$;
д) $\frac{x^2+2}{6} - \frac{3x-1}{8} \le 1$;
е) $2x^2 - \frac{x+1}{2} < \frac{x-3}{3}$.
3.166. Найдите значения аргумента, при которых значения функции:
а) $y = x^2 - 0,25$ больше значений функции $y = \frac{5-2x}{4}$;
б) $y = \frac{x^2}{3}$ не меньше значений функции $y = 2x - 3$.
3.167. Решите неравенство:

б) $\frac{(x-3)^2}{16} - \frac{(x-2)^2}{4} \le 1-x$;
в) $\frac{(2x-1)^2}{10} > \frac{(x-1)^2}{5} + \frac{1-x}{2}$;
г) $\frac{(x-1)^2}{2} + \frac{7}{2} \ge \frac{(x-7)^2}{4} + \frac{x^2-5x}{3}$.
3.168. Найдите значения $k$, при которых уравнение $x^2 + kx + 9 = 0$ имеет два корня.
3.169. Найдите значения $a$, при которых уравнение $x^2 + ax + 16 = 0$ не имеет корней.
3.170. Используя схему графика функции $y = x^2 - 25$, изображенную на рисунке 86, решите неравенство:
а) $x^2 - 25 > 0$;
б) $x^2 - 25 \ge 0$;
в) $x^2 - 25 < 0$;
г) $x^2 - 25 \le 0$.
3.171. Решите квадратное неравенство, используя алгоритм:

в) $x^2 - 7x > 0$;
г) $x^2 - 4 < 0$;
д) $x^2 - 8x + 16 > 0$;
е) $9x^2 + 6x + 1 \le 0$;

3.172. Решите квадратное неравенство:
а) $6x^2 - 7x + 2 > 0$;

в) $x^2 - 1 > 0$;

е) $-2x^2 - 5x + 3 \le 0$;

3.173. Найдите все целые решения неравенства:
а) $x^2 - 4x < 0$;
б) $x^2 - 5x - 6 \le 0$;
в) $x^2 - 6 < 0$;

3.174. Найдите все значения аргумента, при которых функция:
а) $y = 4 + x^2 - 5x$ принимает положительные значения;

3.175. Решите неравенство:

3.176. Решите неравенство:

3.177. Найдите значения переменной, при которых имеет смысл выражение:

3.178. Решите неравенство:

3.179. Найдите значения переменной, при которых значения двучлена $6x^2 - 4x$ меньше значений трехчлена $4x^2 + 3x + 9$.
3.180. Решите неравенство:

3.181. Накануне проведения церемонии награждения победителей ежегодного республиканского фестиваля-ярмарки тружеников села «Дожинки» в зале для проведения торжеств расставляют стулья. Число стульев в каждом ряду должно быть на 15 больше, чем число рядов в зале. Найдите максимальное число рядов стульев, которые можно установить, если в зале одновременно можно разместить не более 250 человек.
3.182. Найдите наименьшее и наибольшее целые решения неравенства:
а) $2(2x^2 - 7) < -8x - 9$;
б) $x(x - 4) \le 2x - 8$;
в) $(x + 5)(x - 7) < -35$;
г) $(x - 8)(x + 3) < 1 - 5x$.
3.183. Решите неравенство:
а) $(x + 3)(x - 2) \le 6 - x^2 - x$;

3.184. Примените формулы сокращенного умножения и решите неравенство:

3.185. Найдите значения переменной, при которых значение квадрата двучлена $3x - 2$ не превосходит значений выражения $3x^2 - 10x + 8$.
3.186. Докажите, что не существует таких значений переменной, при которых выполняется неравенство $-5x^2 + 2x > \frac{1}{5}$.

3.188. Найдите значения аргумента, при которых значения функции $y = x^2 + 2x$ не превосходят значений функции $y = \frac{7x + 3}{4}$.
