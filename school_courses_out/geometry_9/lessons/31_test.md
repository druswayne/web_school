# Тест по теории. Занятие 31. Координаты вектора

**Заданий:** 10  
**Формат:** 4 варианта ответа (а–г). Верных может быть один или несколько. Если в условии сказано «Выберите все верные ответы» — отметьте все подходящие; иначе верный один.

Тест проверяет определения, формулы и правила теории этого занятия.

## Т1. *(Разложение по базису)*

Как называют числа $x$ и $y$ в разложении вектора $c = x\cdot a + y\cdot b$ по двум неколлинеарным векторам $a$ и $b$?

а) Координатами начала вектора
б) Коэффициентами разложения
в) Длинами векторов
г) Координатными векторами

## Т2. *(Единственность разложения)*

Выберите все верные ответы. Какое утверждение о разложении вектора по двум неколлинеарным векторам является верным?

а) Любой вектор на плоскости можно разложить по двум неколлинеарным векторам
б) Такое разложение является единственным
в) Разложение возможно только для нулевого вектора
г) Разложение по двум коллинеарным векторам всегда единственно

## Т3. *(Координатные векторы)*

Какие координаты имеют координатные векторы $i$ и $j$ в прямоугольной системе координат?

а) $i = (0; 1), j = (1; 0)$
б) $i = (1; 1), j = (-1; -1)$
в) $i = (1; 0), j = (0; 1)$
г) $i = (0; 0), j = (1; 1)$

## Т4. *(Разложение по i и j)*

Как записывается разложение вектора $a(x; y)$ по координатным векторам $i$ и $j$?

а) $a = y\cdot i + x\cdot j$
б) $a = x\cdot i + y\cdot j$
в) $a = x\cdot j - y\cdot i$
г) $a = i + j$

## Т5. *(Действия с координатами)*

Выберите все верные ответы. Какие правила относятся к действиям над векторами, заданными координатами?

а) При сложении складывают одноимённые координаты
б) При вычитании вычитают одноимённые координаты
в) При умножении вектора на число умножают только первую координату
г) При умножении вектора на число умножают обе его координаты

## Т6. *(Коллинеарность)*

Какое условие является критерием коллинеарности двух векторов $a$ и $b$?

а) $a = b + k$ для некоторого числа $k$
б) $a = k\cdot b$ для некоторого числа $k$
в) $|a| = |b|$
г) У векторов совпадает только первая координата

## Т7. *(Направление коллинеарных векторов)*

Выберите все верные ответы. Что можно утверждать о коллинеарных векторах $a = k\cdot b$?

а) При $k > 0$ векторы сонаправлены
б) При $k < 0$ векторы противоположно направлены
в) При $k = 1$ векторы обязательно перпендикулярны
г) Для коллинеарности должен существовать один и тот же множитель для обеих координат

## Т8. *(Координаты вектора AB)*

Как находят координаты вектора $AB$, если $A(x_{1}; y_{1})$, а $B(x_{2}; y_{2})$?

а) $AB = (x_{1} - x_{2}; y_{1} - y_{2})$
б) $AB = (x_{1} + x_{2}; y_{1} + y_{2})$
в) $AB = (x_{2} - x_{1}; y_{2} - y_{1})$
г) $AB = (\frac{x_{2}}{x_{1}}; \frac{y_{2}}{y_{1}})$

## Т9. *(Длина вектора)*

Какая формула используется для нахождения длины вектора $a(a_{1}; a_{2})$?

а) $|a| = a_{1}^{2} + a_{2}^{2}$
б) $|a| = \sqrt{a_{1}^{2} + a_{2}^{2}}$
в) $|a| = \sqrt{a_{1} + a_{2}}$
г) $|a| = a_{1} + a_{2}$

## Т10. *(Середина отрезка)*

Выберите все верные ответы. Если $A(x_{1}; y_{1})$ и $B(x_{2}; y_{2})$, то координаты середины $M$ отрезка $AB$ находятся по формулам:

а) $x_{M} = \frac{x_{1} + x_{2}}{2}$
б) $y_{M} = \frac{y_{1} + y_{2}}{2}$
в) $x_{M} = \frac{x_{1} - x_{2}}{2}$
г) $y_{M} = \frac{y_{2} - y_{1}}{2}$
