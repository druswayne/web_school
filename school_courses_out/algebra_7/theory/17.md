# § 13. Формулы сокращенного умножения: произведение суммы и разности двух выражений

**Страницы учебника:** 121–129
**Глава:** 2

## Формулы
$$(a + b)(a - b) = a^2 - b^2$$

## Правила и алгоритмы
### Чтобы выполнить сокращенное умножение суммы и разности двух выражений, нужно:
1. Назвать сумму и разность выражений.
2. Назвать первое и второе выражения.
3. Записать квадрат первого выражения.
4. Поставить знак «минус».
5. Записать квадрат второго выражения.

### Чтобы представить в виде произведения двучленов разность квадратов двух выражений, нужно:
1. Назвать квадрат первого выражения.
2. Назвать первое выражение.
3. Назвать квадрат второго выражения.
4. Назвать второе выражение.
5. Записать произведение суммы и разности этих выражений.

## Ключевые разобранные задания учебника
### Пример: $(x + 8y)(x - 8y) = x^2 - (8y)^2 = x^2 - 64y^2$;
Показывает применение формулы произведения суммы и разности двух выражений.

### Пример: $(a^2 + 5)(a^2 - 5) = (a^2)^2 - 5^2 = a^4 - 25$.
Показывает применение формулы произведения суммы и разности двух выражений для более сложных выражений.

### Пример: $(6m + 7n)(6m - 7n) = (6m)^2 - (7n)^2 = 36m^2 - 49n^2$.
Показывает применение формулы произведения суммы и разности двух выражений с числовыми коэффициентами.

### Пример: Представьте в виде произведения разность квадратов выражений $9a^2 - 16b^2$.
1. $9a^2$ — квадрат первого выражения.
2. $3a$ — первое выражение.
3. $16b^2$ — квадрат второго выражения.
4. $4b$ — второе выражение.
5. $(3a + 4b)(3a - 4b)$.
Показывает алгоритм представления разности квадратов в виде произведения.

## Упражнения параграфа
2.323. Запишите выражение:
а) разность выражений $4m$ и $7b$;
б) разность квадратов выражений $3x$ и $2y$;
в) произведение суммы выражений $5a$ и $4c$ и их разности.
2.324. Представьте в виде квадрата одночлена выражение: а) $36$; б) $b^4$; в) $9x^2$; г) $0,01m^{12}$.

а) $(x - y)(x + y)$;
б) $(m + n)(m - n)$;
в) $(c - d)(c + d)$;
г) $(4x - 1)(4x + 1)$;
д) $(2a + b)(b - 2a)$;
е) $(3y + 5)(5 - 3y)$;
ж) $(3 - 5c)(5c + 3)$;
з) $(7n + 2m)(2m - 7n)$.
2.350. Найдите ошибки в преобразованиях:
а) $(n + m)(m - n) = n^2 - m^2$;
б) $(a + b)(a - b) = a^2 + b^2$.
2.351. Выполните умножение многочленов:
а) $(x^2 + 1)(x^2 - 1)$;
б) $(5 - a^4)(a^4 + 5)$;
в) $(6m^2 - 5n^5)(6m^2 + 5n^5)$;

2.352. Найдите значение выражения:
а) $98 \cdot 102$;
б) $4,9 \cdot 5,1$.
2.353. Представьте в виде многочлена произведение:
а) $(8n + \frac{1}{4}m)(8n - \frac{1}{4}m)$;

в) $(0,4x^2 + 3b)(0,4x^2 - 3b)$;

2.354. Выполните умножение двучленов:
а) $(-n^2 + m)(n^2 + m)$;
б) $(-5a^4 - 3)(5a^4 - 3)$.
2.355. Упростите выражение:
а) $-4(x + 5)(x - 5)$;
б) $(6a^2 - b)(b + 6a^2) - 36a^4$;
в) $0,49n^2 - (0,7n + n^2)(0,7n - n^2)$.
2.356. Решите уравнение $(3x - 1)(1 + 3x) - 9x^2 + 2x + 8 = 12$.
2.357. Представьте в виде многочлена выражение:
а) $(x + 3)^2 - (x - 2)(x + 2)$;
б) $(m + 4n)(m - 4n) - (m - 4n)^2$.
2.358. Упростите выражение $(a - 1)^2 - (5 + a)(a - 5)$ и найдите его значение при $a = -3,5$.
2.359. Докажите, что значение выражения $(-2x + 1)(2x + 1) + (2x + 1)^2 - 4(x - 1)$ не зависит от значения переменной.
2.360. Используя алгоритм, представьте в виде произведения разность квадратов двух выражений:

б) $a^2 - 9$;
в) $m^2 - 1$;
г) $1 - b^6$;
д) $49a^2 - 16$;
е) $64x^8 - 25z^4$.
2.361. Используя формулу разности квадратов, представьте в виде произведения выражения:

б) $0,09a^2 - 0,64c^4$;

2.362. Вычислите значения выражения, не выполняя действия возведения в квадрат:
а) $67^2 - 33^2$;
б) $324,7^2 - 224,7^2$.
2.363. Используя формулу разности квадратов, упростите выражение:
а) $(x - y)^2 - x^2$;
б) $b^2 - (a + b)^2$;
в) $(n + m)^2 - 16n^2$;
г) $4c^2 - (k - 3c)^2$.
2.364. Преобразуйте в многочлен стандартного вида выражение $(b - 5)(b + 5)(b^2 + 25)$.
