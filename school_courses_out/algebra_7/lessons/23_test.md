# Тест по теории. Занятие 23. Линейные уравнения. Линейные неравенства

**Заданий:** 10  
**Формат:** 4 варианта ответа (а–г). Верных может быть один или несколько. Если в условии сказано «Выберите все верные ответы» — отметьте все подходящие; иначе верный один.

Тест проверяет определения, формулы и правила теории этого занятия.

## Т1. *(Определение уравнения)*

Что называется уравнением?

а) Неравенство с переменной
б) Равенство с переменной
в) Любое числовое выражение
г) Равенство, в котором нет переменных

## Т2. *(Корень уравнения)*

Выберите все верные ответы. Корнем уравнения называется:

а) значение переменной, которое обращает уравнение в верное числовое равенство
б) любое число, записанное в уравнении
в) значение переменной, удовлетворяющее уравнению
г) только положительное значение переменной

## Т3. *(Линейное уравнение)*

Какое уравнение называют линейным?

а) Уравнение вида ax = b, где a и b — числа
б) Любое уравнение со скобками
в) Уравнение, в котором переменная находится только в знаменателе
г) Уравнение вида ax² = b

## Т4. *(Перенос слагаемых)*

Как изменяется слагаемое при переносе из одной части уравнения в другую?

а) Его знак изменяется на противоположный
б) Его знак всегда становится положительным
в) Его значение удваивается
г) Оно заменяется на нуль

## Т5. *(Равносильность уравнений)*

Выберите все верные ответы. Равносильное уравнение можно получить, если:

а) перенести слагаемое из одной части в другую, изменив его знак
б) умножить обе части на одно и то же отличное от нуля число
в) разделить только левую часть на ненулевое число
г) изменить знак только одного слагаемого

## Т6. *(Свойство неравенств)*

Что происходит со знаком неравенства при прибавлении одного и того же числа к обеим его частям?

а) Знак меняется на противоположный
б) Знак не изменяется
в) Знак становится равенством
г) Знак можно выбрать произвольно

## Т7. *(Умножение на отрицательное число)*

Выберите все верные ответы. При умножении или делении обеих частей неравенства на отрицательное число:

а) знак неравенства меняется на противоположный
б) порядок чисел сохраняется
в) необходимо изменить направление знака
г) знак изменяется только при умножении, но не при делении

## Т8. *(Почленное сложение)*

Какая формула выражает правило почленного сложения неравенств одного знака?

а) Если a < b и c < d, то a + c < b + d
б) Если a < b и c < d, то a + d < b + c
в) Если a < b и c < d, то ac < bd всегда
г) Если a < b и c < d, то a − c < b − d

## Т9. *(Почленное умножение)*

Выберите все верные ответы. Почленное умножение неравенств можно применять, если:

а) неравенства имеют одинаковое направление
б) все четыре части неравенств положительны
в) среди частей есть отрицательные числа, но это не проверяется
г) произведения меньших частей сравниваются с произведением больших частей

## Т10. *(Формула линейного уравнения)*

Какая формула задаёт решение линейного уравнения ax = b при a ≠ 0?

а) x = ab
б) x = a / b
в) x = b / a
г) x = a − b
