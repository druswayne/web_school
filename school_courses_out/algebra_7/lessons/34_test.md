# Тест по теории. Занятие 34. Решение текстовых задач с помощью системы линейных уравнений

**Заданий:** 10  
**Формат:** 4 варианта ответа (а–г). Верных может быть один или несколько. Если в условии сказано «Выберите все верные ответы» — отметьте все подходящие; иначе верный один.

Тест проверяет определения, формулы и правила теории этого занятия.

## Т1. *(Признак системы)*

В каком случае для решения текстовой задачи обычно составляют систему двух линейных уравнений с двумя переменными?

а) Если нужно найти одну неизвестную величину и дано одно условие
б) Если нужно найти две неизвестные величины и имеются два независимых условия
в) Если в задаче нет известных величин
г) Если все величины уже известны

## Т2. *(Обозначение неизвестных)*

Какое действие выполняют первым при решении текстовой задачи с помощью системы уравнений?

а) Сразу записывают ответ
б) Подставляют случайные числа в условие
в) Определяют неизвестные величины и обозначают их через переменные
г) Округляют все данные

## Т3. *(Общий вид системы)*

Выберите все верные ответы. Какой вид может иметь система двух линейных уравнений с двумя переменными?

а) $$\begin{cases}a_{1}x+b_{1}y=c_{1},\\a_{2}x+b_{2}y=c_{2}.
\end{cases}$$
б) $$\begin{cases}a_{1}x^{2}+b_{1}y=c_{1},\\a_{2}x+b_{2}y=c_{2}.
\end{cases}$$
в) $$\begin{cases}3x-2y=5,\\x+y=7.
\end{cases}$$
г) $$\begin{cases}\frac{1}{x}+y=4,\\x-y=1.
\end{cases}$$

## Т10. *(Проверка решения)*
