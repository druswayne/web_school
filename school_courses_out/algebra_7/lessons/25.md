# Занятие 25. Функция

**Раздел:** Глава 3  
**Параграф учебника:** §19. Функция  
**Страницы:** 210–230

## Цели занятия

К концу занятия ученик сможет:

- определять, является ли зависимость функцией;
- находить значение функции по таблице, формуле и графику;
- определять область определения $D(f)$ и множество значений $E(f)$;
- находить нули функции;
- определять по графику, где функция положительна или отрицательна;
- проверять, является ли изображённая линия графиком функции.

Выбирай блок своего уровня:

- **1–2 балла** — понять определение функции и читать значения по таблице;
- **3–4 балла** — вычислять значения функции по формуле, находить $D(f)$ и $E(f)$;
- **5–6 баллов** — работать с графиком, находить нули и знаки функции;
- **7–8 баллов** — решать смешанные задания;
- **9–10 баллов** — уверенно применять все способы задания функции и замечать ловушки.

## Теория к занятию

### 1. Что такое функция

#### Простыми словами

Смотри: есть две переменные. Одну выбираем сами — это аргумент. По выбранному значению находим вторую переменную — значение функции.

Главное условие: каждому допустимому значению аргумента должно соответствовать ровно одно значение функции.

Можно представить автомат: ввели одно число — получили один результат. Если на один и тот же ввод автомат выдаёт два разных ответа, это уже не функция, а математический сюрпризник.

#### Определение

**Зависимость между двумя переменными, при которой каждому значению одной переменной (аргументу) соответствует единственное значение другой переменной (функции), называется функциональной зависимостью или функцией.**

#### Формулы

Функцию часто записывают так:

$$y=f(x).$$

Здесь:

- $x$ — аргумент;
- $y$ — значение функции;
- $f$ — обозначение зависимости.

Примеры:

$$s=vt,$$

где $s$ — пройденный путь, $v$ — скорость, $t$ — время;

$$m=0,52+0,71\cdot V,$$

где $m$ — масса канистры с бензином, $V$ — объём бензина;

$$C=a+b\cdot s,$$

где $C$ — стоимость поездки, $a$ — плата за вызов, $b$ — плата за 1 км, $s$ — расстояние;

$$y=1,6x,$$

где $x$ — число миль, $y$ — число километров.

#### Правила

- Одному значению аргумента должно соответствовать **единственное** значение функции.
- Разным значениям аргумента могут соответствовать одинаковые значения функции.
- Если хотя бы одному аргументу соответствуют два разных значения функции, зависимость функцией не является.

Например, двум разным значениям $x$ могут соответствовать одинаковые значения $y$. Это не мешает зависимости быть функцией.

#### Алгоритм проверки зависимости

1. Выбрать значение аргумента.
2. Проверить, получается ли при нём только одно значение функции.
3. Повторить проверку для всех допустимых значений аргумента.
4. Если условие выполняется всегда, зависимость является функцией.
5. Если хотя бы для одного аргумента получаются два разных значения функции, зависимость функцией не является.

#### Ловушки

- Несколько аргументов могут иметь одно и то же значение функции. Это разрешено.
- Условие «одному значению функции соответствует один аргумент» для функции не требуется.
- Нельзя без проверки менять местами аргумент и функцию.
- Например, одинаковый рост могут иметь люди с разным весом. Поэтому рост человека не задаёт его вес однозначно.

### 2. Способы задания функции

#### Простыми словами

Функцию можно задать:

- таблицей;
- графиком;
- формулой.

Во всех случаях мы хотим узнать одно и то же: какое значение функции соответствует данному аргументу. Просто «упаковка» разная.

#### Табличный способ задания функции

**Функция задана таблично, если в первой строке таблицы записаны значения аргумента, а во второй — соответствующие значения функции.**

Например:

| $x$ | $-3$ | $0$ | $2$ | $5$ |
|---|---:|---:|---:|---:|
| $f(x)$ | $4$ | $1$ | $-2$ | $4$ |

Читаем таблицу по столбцам:

$$f(-3)=4,$$

$$f(0)=1,$$

$$f(2)=-2,$$

$$f(5)=4.$$

#### Графический способ задания функции

**Функция задана графически, если ее график изображен на координатной плоскости. Значения аргумента отмечаются на оси абсцисс, а значения функции — на оси ординат.**

Чтобы найти $f(a)$ по графику:

1. На оси абсцисс найти число $a$.
2. Провести из этой точки вертикальную линию до графика.
3. Из найденной точки графика провести горизонтальную линию к оси ординат.
4. Считать значение на оси ординат. Это и есть $f(a)$.

Не перепутай: сначала идём по оси $x$, потом поднимаемся к графику, затем читаем значение по оси $y$.

#### Аналитический способ задания функции

**Функция задана аналитически, или формулой, если зависимость между переменными выражена формулой.**

Например:

$$f(x)=5x-1.$$

Чтобы найти значение функции, вместо $x$ подставляют нужное число и выполняют вычисления.

#### Ловушки

- В таблице значение функции нужно искать в том же столбце, где находится аргумент.
- На графике аргумент ищут по горизонтальной оси.
- Запись $f(3)$ означает значение функции при $x=3$, а не произведение $f\cdot3$.
- Ось $x$ горизонтальная, а ось $y$ вертикальная. Если поменять их местами, график начнёт рассказывать совсем другую историю.

### 3. Область определения и множество значений

#### Простыми словами

У каждой функции есть два важных набора чисел.

Область определения отвечает на вопрос:

> Какие значения аргумента можно использовать?

Множество значений отвечает на вопрос:

> Какие результаты функции получаются?

#### Определение

**Множество всех значений, которые принимает аргумент, называется областью определения функции.**

**Все значения, которые принимает функция, называются множеством значений функции.**

Область определения обозначается $D(f)$.

Множество значений функции обозначается $E(f)$.

#### Правила

Для функции, заданной таблицей:

- $D(f)$ — все числа из первой строки;
- $E(f)$ — все разные числа из второй строки.

Для функции, заданной формулой:

- если описание процесса не дано, в область определения входят те значения аргумента, при которых формула имеет смысл;
- делить на нуль нельзя.

Например, в функции

$$f(x)=\frac{x}{x+5}$$

нельзя взять $x=-5$, потому что тогда знаменатель станет равен нулю:

$$x+5=-5+5=0.$$

Для функции, заданной графиком:

- $D(f)$ — значения абсцисс точек графика;
- $E(f)$ — значения ординат точек графика.

#### Ловушки

- Повторяющиеся значения в $E(f)$ записывают только один раз.
- $D(f)$ читают по оси $x$.
- $E(f)$ читают по оси $y$.
- В функции $f(x)=\dfrac{x}{x+5}$ число $-5$ не входит в область определения.
- $D(f)$ и $E(f)$ похожи по записи, но отвечают на разные вопросы: одно множество про аргументы, другое — про результаты.

### 4. Значение функции по формуле

#### Простыми словами

Формула функции — это инструкция для вычисления. Подставили значение аргумента, посчитали — получили значение функции.

Например, если

$$f(x)=5x-1,$$

то при $x=a$ получаем:

$$f(a)=5a-1.$$

Если задано

$$f(x)=\frac{x}{x+5},$$

сначала нужно убедиться, что знаменатель не равен нулю.

#### Алгоритм

1. Записать формулу функции.
2. Подставить значение аргумента вместо каждой буквы $x$.
3. Если число отрицательное, заключить его в скобки.
4. Выполнить действия по порядку.
5. Проверить, допустимо ли подставленное значение.

#### Пример

Пусть

$$f(x)=5x-1.$$

Найдём $f(-3)$:

$$f(-3)=5\cdot(-3)-1,$$

$$f(-3)=-15-1,$$

$$f(-3)=-16.$$

Минус без скобок иногда превращает решение в математический детектив. Скобки сразу показывают, какое число мы подставили.

#### Ловушки

- При подстановке отрицательного числа нужны скобки.
- В дроби число нужно подставить и в числитель, и в знаменатель.
- При вычислении $f(-3)$ выражение $5x$ превращается в $5\cdot(-3)$, а не в $5\cdot3$.
- Перед вычислением проверь, не становится ли знаменатель равным нулю.

---

### 5. Нули функции и знаки функции

#### Простыми словами

Нуль функции — это такое значение аргумента, при котором значение функции равно нулю.

На графике нули находятся там, где график пересекает или касается оси $x$.

#### Определение

**Значения аргумента, при которых значения функции равны нулю, называются нулями функции.**

#### Алгоритм нахождения нулей по формуле

1. Записать условие $f(x)=0$.
2. Подставить вместо $f(x)$ формулу функции.
3. Решить полученное уравнение.
4. Проверить найденное значение подстановкой.

#### Пример

Найдём нуль функции

$$f(x)=-3x+2.$$

Приравниваем функцию к нулю:

$$-3x+2=0.$$

Переносим $2$ в правую часть:

$$-3x=-2.$$

Делим обе части на $-3$:

$$x=\frac{-2}{-3},$$

$$x=\frac{2}{3}.$$

Значит, нуль функции равен $\dfrac{2}{3}$.

#### Как определить знак функции по графику

- если график расположен выше оси абсцисс, функция положительна;
- если график расположен ниже оси абсцисс, функция отрицательна;
- если график находится на оси абсцисс, функция равна нулю.

#### Ловушки

- Нуль функции — это значение $x$, а не вся точка $(x;0)$.
- В самих нулях функция не положительна и не отрицательна: она равна нулю.
- Нули ищут по пересечениям с горизонтальной осью $x$.
- Знак функции определяют по высоте графика над осью $x$, а не по тому, идёт график вверх или вниз.

---

### 6. График функции

#### Простыми словами

График функции состоит из точек с координатами $(x;y)$, где

$$y=f(x).$$

Первая координата показывает аргумент, вторая — значение функции.

Для каждого значения $x$ на графике должна быть не более чем одна точка. Иначе одному аргументу соответствовали бы два значения функции.

#### Определение

**Графиком функции называется множество всех точек координатной плоскости, абсциссы которых равны значениям аргумента, а ординаты — значениям функции.**

#### Проверка графика вертикальной прямой

Представь, что двигаешь вертикальную прямую слева направо:

- если в каждом месте она пересекает линию не более чем в одной точке, линия может быть графиком функции;
- если хотя бы в одном месте она пересекает линию в двух или более точках, линия не является графиком функции.

Это удобная проверка: одна вертикаль — один возможный ответ.

#### Ловушки

- Горизонтальная прямая может быть графиком функции.
- Вертикальная прямая графиком функции не является.
- Окружность не является графиком функции: одной абсциссе могут соответствовать две ординаты.
- Красивый рисунок сам по себе ничего не доказывает. Вертикальная проверка строже любого художественного впечатления.

---

## Сводка формул «выучить наизусть»

$$s=vt,$$

$$m=0,52+0,71\cdot V,$$

$$C=a+b\cdot s,$$

$$y=1,6x.$$

Для нахождения нулей функции:

$$f(x)=0.$$

Для функции, заданной формулой $f(x)=kx+b$, нуль находят из уравнения:

$$kx+b=0.$$

## Правила, которые нельзя путать

- $D(f)$ — область определения, значения аргумента.
- $E(f)$ — множество значений функции.
- Нуль функции — значение аргумента, при котором $f(x)=0$.
- По оси $x$ читают аргумент.
- По оси $y$ читают значение функции.
- В функции одному аргументу соответствует единственное значение функции.
- Для проверки графика используют вертикальную прямую.

## Разбор ключевых заданий

### Р1. Определение функции

**Условие.** Какие зависимости являются функциями:

а) между числом купленных тетрадей и стоимостью покупки;  
б) между оценкой за контрольную работу и номером учащегося по списку;  
в) между длиной стороны квадрата и его площадью;  
г) между периметром треугольника и его наибольшей стороной?

**Решение.**

Проверяем каждую зависимость: одному значению первой величины должно соответствовать только одно значение второй.

а) При фиксированной цене одной тетради каждому числу купленных тетрадей соответствует одна стоимость покупки.

Значит, зависимость является функцией.

б) Одну и ту же оценку могут получить несколько учащихся.

Значит, одному значению оценки могут соответствовать разные номера учащихся.

Зависимость не является функцией.

в) Площадь квадрата со стороной $a$ вычисляется по формуле:

$$S=a^2.$$

Каждой длине стороны соответствует одно значение площади.

Значит, зависимость является функцией.

г) Одному и тому же периметру могут соответствовать треугольники с разными наибольшими сторонами.

Значит, одному значению периметра могут соответствовать разные значения наибольшей стороны.

Зависимость не является функцией.

Здесь ловушка в том, что одинаковый периметр ещё не заставляет треугольники быть одинаковыми.

**Ответ:** функциями являются зависимости а) и в).

### Р2. Смежные углы

**Условие.** Величины смежных углов равны $\alpha$ и $\beta$. Задайте формулой зависимость $\beta$ от $\alpha$. Является ли эта зависимость функцией?

**Решение.**

Смежные углы в сумме дают $180^\circ$:

$$\alpha+\beta=180^\circ.$$

Нужно выразить $\beta$ через $\alpha$.

Вычтем $\alpha$ из обеих частей равенства:

$$\beta=180^\circ-\alpha.$$

Получили формулу зависимости $\beta$ от $\alpha$.

Каждому допустимому значению $\alpha$ соответствует только одно значение $\beta$.

Следовательно, зависимость является функцией.

Величины углов должны быть положительными и меньше $180^\circ$:

$$0^\circ<\alpha<180^\circ,$$

$$0^\circ<\beta<180^\circ.$$

Смежные углы не спорят, кто главнее: вместе они всегда набирают ровно $180^\circ$.

**Ответ:** $\beta=180^\circ-\alpha$; зависимость является функцией.

### Р3. Табличное задание функции

**Условие.** Функция задана таблицей.

| $x$ | $-3$ | $0$ | $4$ | $8,6$ | $10$ |
|---|---:|---:|---:|---:|---:|
| $f(x)$ | $2$ | $-1$ | $5$ | $0$ | $5$ |

Найдите:

а) $f(4)$, $f(8,6)$, $f(10)$;  
б) $D(f)$;  
в) $E(f)$.

**Решение.**

а) Находим нужное число в первой строке и смотрим значение под ним во второй строке:

$$f(4)=5,$$

$$f(8,6)=0,$$

$$f(10)=5.$$

б) Область определения — это все значения аргумента из первой строки:

$$D(f)=\{-3;0;4;8,6;10\}.$$

в) Множество значений функции составляют числа из второй строки:

$$2,\ -1,\ 5,\ 0,\ 5.$$

Число $5$ повторяется, поэтому в множество записываем его только один раз:

$$E(f)=\{-1;0;2;5\}.$$

Таблица читается по вертикали: один столбец — одна пара «аргумент — значение функции».

**Ответ:**  
а) $5;0;5$;  
б) $D(f)=\{-3;0;4;8,6;10\}$;  
в) $E(f)=\{-1;0;2;5\}$.

### Р4. Значения функции по формуле

**Условие.** Функция задана формулой:

$$f(x)=\frac{x}{x+5}.$$

Найдите $f(-4)$, $f(0)$, $f(3)$.

**Решение.**

Чтобы вычислить значение функции, подставляем нужное число вместо $x$.

Сначала проверим, что знаменатель не равен нулю:

$$-4+5=1\ne0,$$

$$0+5=5\ne0,$$

$$3+5=8\ne0.$$

Все три значения можно подставлять в формулу.

Найдём $f(-4)$:

$$f(-4)=\frac{-4}{-4+5},$$

$$f(-4)=\frac{-4}{1},$$

$$f(-4)=-4.$$

Найдём $f(0)$:

$$f(0)=\frac{0}{0+5},$$

$$f(0)=\frac{0}{5},$$

$$f(0)=0.$$

Найдём $f(3)$:

$$f(3)=\frac{3}{3+5},$$

$$f(3)=\frac{3}{8}.$$

Знаменатель не равен нулю, поэтому вычисление выполнено правильно. Дробь сегодня ведёт себя прилично.

**Ответ:** $f(-4)=-4$, $f(0)=0$, $f(3)=\dfrac{3}{8}$.

### Р7. Нули функции, заданной формулой

**Условие.** Найдите нули функций:

а) $f(x)=-3x+2$;  
б) $f(x)=9-4x$.

**Решение.**

Нуль функции — это такое значение $x$, при котором значение функции равно нулю.

а) Приравняем функцию к нулю:

$$-3x+2=0.$$

Перенесём $2$ в правую часть:

$$-3x=-2.$$

Разделим обе части уравнения на $-3$:

$$x=\frac{-2}{-3}.$$

Сократим знаки минус:

$$x=\frac{2}{3}.$$

Проверим найденное значение:

$$-3\cdot\frac23+2=-2+2=0.$$

Значит, $x=\dfrac23$ — нуль функции.

б) Приравняем функцию к нулю:

$$9-4x=0.$$

Перенесём $9$ в правую часть:

$$-4x=-9.$$

Разделим обе части уравнения на $-4$:

$$x=\frac{-9}{-4}.$$

Сократим знаки минус:

$$x=\frac94.$$

Проверим:

$$9-4\cdot\frac94=9-9=0.$$

Значит, $x=\dfrac94$ — нуль функции.

**Ответ:**  
а) $x=\dfrac23$;  
б) $x=\dfrac94$.

### Р8. Проверка равенства значений функции

**Условие.** Верно ли, что $g(3)+g(5)=g(6)$, если

$$g(x)=x^2+1?$$

**Решение.**

Сначала найдём значение $g(3)$:

$$g(3)=3^2+1,$$

$$g(3)=9+1,$$

$$g(3)=10.$$

Теперь найдём значение $g(5)$:

$$g(5)=5^2+1,$$

$$g(5)=25+1,$$

$$g(5)=26.$$

Сложим найденные значения:

$$g(3)+g(5)=10+26=36.$$

Отдельно найдём $g(6)$:

$$g(6)=6^2+1,$$

$$g(6)=36+1,$$

$$g(6)=37.$$

Сравним результаты:

$$36\ne37.$$

Значит, равенство неверно. Функция не обязана превращать сумму двух значений в ещё одно нужное значение — она работает по своей формуле.

**Ответ:** нет, равенство неверно.

### Р9. Является ли линия графиком функции

**Условие.** Определите, какие из линий могут быть графиками функций:

а) прямая $y=2x-1$;  
б) вертикальная прямая $x=3$;  
в) окружность с центром в начале координат.

**Решение.**

Проверяем главное условие функции: каждому значению $x$ должно соответствовать только одно значение $y$.

а) Для каждого значения $x$ по формуле

$$y=2x-1$$

получается единственное значение $y$.

Значит, эта прямая является графиком функции.

б) На вертикальной прямой $x=3$ лежит много точек с разными ординатами.

Получается, одному значению аргумента $x=3$ соответствуют разные значения $y$.

Значит, вертикальная прямая не является графиком функции.

в) Возьмём вертикальную прямую $x=0$.

Она пересекает окружность в двух точках.

У этих точек одинаковая абсцисса $x=0$, но разные ординаты $y$.

Значит, одному значению аргумента соответствуют два значения функции.

Окружность не является графиком функции.

Удобная проверка: мысленно проведите вертикальную прямую. Если она встречает линию два раза, функция сказала: «Нет, так не договаривались».

**Ответ:** только прямая $y=2x-1$ может быть графиком функции.
