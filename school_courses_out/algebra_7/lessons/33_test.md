# Тест по теории. Занятие 33. Системы двух линейных уравнений с двумя переменными

**Заданий:** 10  
**Формат:** 4 варианта ответа (а–г). Верных может быть один или несколько. Если в условии сказано «Выберите все верные ответы» — отметьте все подходящие; иначе верный один.

Тест проверяет определения, формулы и правила теории этого занятия.

## Т1. *(Определение системы)*

Какое утверждение правильно определяет систему двух линейных уравнений с двумя переменными?

а) Два уравнения, каждое из которых содержит только одну переменную.
б) Два уравнения, которые должны выполняться одновременно для одних и тех же значений переменных.
в) Два неравенства, объединённые знаком равенства.
г) Одно уравнение, записанное дважды с разными переменными.

## Т2. *(Решение системы)*

Выберите все верные ответы. Что называют решением системы уравнений с двумя переменными?

а) Пару значений переменных, при которых верны оба уравнения системы.
б) Пару, записанную в виде $(x;y)$.
в) Значение только одной переменной, найденное из первого уравнения.
г) Любую точку, принадлежащую хотя бы одной из двух прямых.

## Т3. *(Общий вид уравнения)*

Как записывается общий вид линейного уравнения с двумя переменными?

а) $ax+by=c$
б) $ax^{2}+by^{2}=c$
в) $y=kx+b^{2}$
г) $\frac{a}{x}+\frac{b}{y}=c$

## Т4. *(Графический смысл)*

Выберите все верные ответы. Каков графический смысл решения системы двух линейных уравнений?

а) Это координаты общей точки двух графиков.
б) Это координаты точки пересечения двух прямых, если они пересекаются.
в) Это любая точка одной из прямых.
г) При совпадении прямых система имеет бесконечно много решений.

## Т5. *(Число решений)*

Какое утверждение о числе решений системы соответствует взаимному расположению её графиков?

а) Пересекающиеся прямые имеют бесконечно много общих точек.
б) Параллельные прямые имеют ровно одну общую точку.
в) Совпадающие прямые имеют бесконечно много общих точек.
г) Любые две прямые имеют ровно одну общую точку.

## Т6. *(Способ подстановки)*

Выберите все верные утверждения о способе подстановки.

а) Сначала из одного уравнения выражают одну переменную через другую.
б) Полученное выражение полностью подставляют во второе уравнение.
в) После нахождения одной переменной вторую находить необязательно.
г) Если перед подставляемым выражением стоит минус, выражение заключают в скобки.

## Т7. *(Способ сложения)*

Что необходимо делать при применении способа сложения к системе уравнений?

а) Складывать только левые части уравнений.
б) При необходимости умножать уравнение целиком на подходящее число, а затем складывать почленно обе части.
в) Менять знак только у свободного члена.
г) Складывать только коэффициенты при переменных.

## Т8. *(Тождественные преобразования)*

Выберите все преобразования, которые не изменяют множество решений уравнения. Выберите все верные ответы.

а) Раскрытие скобок.
б) Перенос слагаемого из одной части равенства в другую с изменением знака.
в) Умножение обеих частей уравнения на одно и то же ненулевое число.
г) Умножение только левой части уравнения на ненулевое число.

## Т9. *(Формулы сокращённого умножения)*

Выберите все верные формулы сокращённого умножения.

а) $a^{2}-b^{2}=(a-b)(a+b)$
б) $(a+b)^{2}=a^{2}+2ab+b^{2}$
в) $(a-b)^{2}=a^{2}-2ab+b^{2}$
г) $(a-b)^{2}=a^{2}-b^{2}$

## Т10. *(Координатные оси)*

Выберите все верные утверждения о координатных осях и прямых.

а) Уравнение оси абсцисс имеет вид $y=0$.
б) Уравнение оси ординат имеет вид $x=0$.
в) Прямая, параллельная графику $y=kx+b$, имеет тот же коэффициент $k$.
г) Уравнение оси абсцисс имеет вид $x=0$.
