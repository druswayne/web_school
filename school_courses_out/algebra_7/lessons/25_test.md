# Тест по теории. Занятие 25. Функция

**Заданий:** 10  
**Формат:** 4 варианта ответа (а–г). Верных может быть один или несколько. Если в условии сказано «Выберите все верные ответы» — отметьте все подходящие; иначе верный один.

Тест проверяет определения, формулы и правила теории этого занятия.

## Т1. *(Определение функции)*

Какое утверждение является определением функции?

а) Каждому значению функции соответствует ровно одно значение аргумента.
б) Каждому допустимому значению аргумента соответствует ровно одно значение функции.
в) Каждому значению аргумента соответствуют не менее двух значений функции.
г) Значения аргумента и функции всегда совпадают.

## Т2. *(Обозначения функции)*

В записи $y=f(x)$ выберите все верные ответы. Выберите все верные ответы.

а) $x$ — аргумент.
б) $y$ — значение функции.
в) $f$ — обозначение зависимости.
г) $x$ — множество значений функции.

## Т3. *(Способы задания)*

Какими основными способами может быть задана функция?

а) Табличным, графическим и аналитическим.
б) Только табличным и графическим.
в) Только формулой.
г) Только с помощью координатных осей.

## Т4. *(Табличный способ)*

Как определяется область определения функции, заданной таблицей?

а) Как множество всех чисел из второй строки таблицы.
б) Как множество различных чисел из второй строки таблицы.
в) Как множество всех чисел из первой строки таблицы.
г) Как множество чисел, которые встречаются в обеих строках.

## Т5. *(Область определения)*

Выберите все верные утверждения об области определения функции. Выберите все верные ответы.

а) Область определения обозначается $D(f)$.
б) Область определения состоит из значений аргумента.
в) Для дробно-рациональной функции исключаются значения, обращающие знаменатель в нуль.
г) Область определения состоит только из положительных значений функции.

## Т6. *(Множество значений)*

Что называется множеством значений функции?

а) Все значения аргумента, при которых функция определена.
б) Все значения, которые принимает функция.
в) Только нули функции.
г) Все абсциссы точек графика.

## Т7. *(Координатные оси)*

Выберите все верные утверждения о координатах точек графика функции. Выберите все верные ответы.

а) Значения аргумента отмечаются на оси абсцисс.
б) Значения функции отмечаются на оси ординат.
в) Ось абсцисс является горизонтальной осью.
г) Ось ординат является горизонтальной осью.

## Т8. *(Нули функции)*

Что называется нулем функции?

а) Точка пересечения графика с осью ординат.
б) Значение функции, равное единице.
в) Значение аргумента, при котором значение функции равно нулю.
г) Любая точка графика, имеющая нулевую ординату.

## Т9. *(Знаки функции)*

Выберите все верные утверждения о знаке функции по её графику. Выберите все верные ответы.

а) Выше оси абсцисс функция положительна.
б) Ниже оси абсцисс функция отрицательна.
в) На оси абсцисс функция равна нулю.
г) Направление движения графика всегда определяет знак функции.

## Т10. *(Проверка графика)*

Как проверяют, может ли изображённая линия быть графиком функции?

а) Проводят мысленно горизонтальную прямую и проверяют число пересечений.
б) Проводят мысленно вертикальную прямую: она должна пересекать линию не более чем в одной точке.
в) Проверяют, проходит ли линия через начало координат.
г) Проверяют, является ли линия прямой.
