# Тест по теории. Занятие 27. Линейная функция

**Заданий:** 10  
**Формат:** 4 варианта ответа (а–г). Верных может быть один или несколько. Если в условии сказано «Выберите все верные ответы» — отметьте все подходящие; иначе верный один.

Тест проверяет определения, формулы и правила теории этого занятия.

## Т1. *(Определение)*

Какая функция называется линейной?

а) Функция вида y = kx + b, где k и b — некоторые числа
б) Функция вида y = kx² + b, где k и b — некоторые числа
в) Функция вида y = k/x + b, где k и b — некоторые числа
г) Функция вида y = k + b/x, где k и b — некоторые числа

## Т2. *(Параметры функции)*

В формуле линейной функции y = kx + b число k является:

а) свободным членом
б) аргументом
в) коэффициентом при x
г) значением функции

## Т3. *(График)*

Что представляет собой график линейной функции?

а) окружность
б) прямая
в) парабола
г) ломаная линия

## Т4. *(Направление графика)*

Выберите все верные ответы. Как ведёт себя график линейной функции в зависимости от коэффициента k?

а) При k > 0 прямая поднимается слева направо
б) При k < 0 прямая спускается слева направо
в) При k = 0 график является горизонтальной прямой
г) При k < 0 график обязательно является вертикальной прямой

## Т5. *(Ось ординат)*

Какая координата равна нулю у любой точки оси ординат?

а) ордината y
б) абсцисса x
в) коэффициент k
г) свободный член b

## Т6. *(Пересечение с осью ординат)*

Как записывается точка пересечения графика функции y = kx + b с осью ординат?

а) (b; 0)
б) (0; k)
в) (0; b)
г) (k; b)

## Т7. *(Параллельность)*

Выберите все верные ответы. Какие условия связаны с параллельностью графиков линейных функций?

а) У параллельных графиков коэффициенты при x одинаковы
б) Изменение свободного члена b сдвигает прямую вверх или вниз
в) Одинаковые значения b всегда означают параллельность графиков
г) Для параллельности важен коэффициент k, а не только свободный член b

## Т8. *(Пересечение графиков)*

Какое равенство используют для нахождения абсциссы точки пересечения графиков функций y = k₁x + b₁ и y = k₂x + b₂?

а) k₁x + b₁ = k₂x + b₂
б) k₁x + b₁ = 0
в) k₁ = k₂
г) b₁ = b₂

## Т9. *(Оси координат)*

Выберите все верные ответы. Какие утверждения об осях координат правильны?

а) Для точки на оси ординат x = 0
б) Для точки на оси абсцисс y = 0
в) Чтобы найти пересечение с осью ординат, подставляют y = 0
г) Чтобы найти пересечение с осью абсцисс, подставляют y = 0

## Т10. *(Порядок нахождения точки)*

Каков правильный порядок нахождения точки пересечения двух графиков линейных функций?

а) Приравнять правые части, найти x, подставить x в одну из формул и найти y
б) Приравнять свободные члены, найти y, затем найти x
в) Приравнять коэффициенты при x, затем записать точку (0; b)
г) Сначала положить y = 0, затем сравнить свободные члены
