# Тест по теории. Занятие 6. Тождество

**Заданий:** 10  
**Формат:** 4 варианта ответа (а–г). Верных может быть один или несколько. Если в условии сказано «Выберите все верные ответы» — отметьте все подходящие; иначе верный один.

Тест проверяет определения, формулы и правила теории этого занятия.

## Т1. *(Определение тождественно равных выражений)*

Какие выражения называются тождественно равными?

а) Выражения, принимающие одинаковые значения хотя бы при одном значении переменной.
б) Выражения, принимающие одинаковые значения при всех значениях переменных из их общей области определения.
в) Выражения, записанные с использованием одинаковых букв.
г) Выражения, значения которых всегда являются целыми числами.

## Т2. *(Определение тождества)*

Что называют тождеством?

а) Равенство двух выражений, верное только при одном значении переменной.
б) Любое равенство, содержащее переменные.
в) Равенство двух тождественно равных выражений.
г) Равенство двух чисел, полученных после подстановки.

## Т3. *(Общая область определения)*

Что называют общей областью определения двух выражений?

а) Все значения переменных, при которых имеет смысл только первое выражение.
б) Все значения переменных, при которых имеет смысл только второе выражение.
в) Все значения переменных, при которых имеют смысл и первое, и второе выражения.
г) Все значения переменных, при которых выражения принимают равные значения.

## Т4. *(Тождественное преобразование)*

Что называют тождественным преобразованием выражения?

а) Замену выражения другим выражением, тождественно равным ему.
б) Замену переменной конкретным числом.
в) Изменение значения выражения с помощью арифметических действий.
г) Удаление всех переменных из выражения.

## Т5. *(Законы действий)*

Выберите все верные равенства.

а) $a+b=b+a$
б) $a(b+c)=ab+ac$
в) $a-b=b-a$
г) $a+(b+c)=(a+b)+c$

## Т6. *(Распределительный закон)*

Как правильно раскрывается скобка в произведении $a(b-c)$?

а) $a(b-c)=ab+ac$
б) $a(b-c)=ab-ac$
в) $a(b-c)=a-bc$
г) $a(b-c)=ab-c$

## Т7. *(Отрицательный знак и квадрат)*

Выберите все верные равенства.

а) $(-a)^{2}=a^{2}$
б) $-a^{2}=a^{2}$
в) $(-a)^{3}=-a^{3}$
г) $(-a)^{2}=-a^{2}$

## Т8. *(Свойства степеней)*

Выберите все верные формулы свойств степеней.

а) $a^{m}\cdot a^{n}=a^{m+n}$
б) $a^{m}:a^{n}=a^{m-n}$, при $a\neq 0$
в) $(a^{m})^{n}=a^{m+n}$
г) $(a^{m})^{n}=a^{mn}$

## Т9. *(Доказательство тождества)*

Как обычно доказывают тождественное равенство двух выражений?

а) Проверяют равенство только при нулевом значении переменной.
б) Преобразуют одно выражение в другое, используя законы и свойства действий.
в) Сравнивают выражения по их внешнему виду.
г) Подбирают одно значение переменной, при котором выражения равны.

## Т10. *(Опровержение тождества)*

Выберите все верные утверждения о доказательстве того, что выражения не являются тождественно равными.

а) Достаточно найти одно допустимое значение переменной, при котором значения выражений различаются.
б) Можно выбрать значение, при котором одно из выражений не имеет смысла.
в) Для опровержения тождества используют контрпример.
г) Если при одном значении выражения равны, тождественное равенство доказано.
