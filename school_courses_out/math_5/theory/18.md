# § 16. Выражения с переменными

**Страницы учебника:** 118–124
**Глава:** 2. Выражения. Уравнения

## Определения
### Определение. Выражение с переменной
Если количество пакетов сока обозначить буквой, например, $k$, то получится выражение для решения задачи с любым количеством пакетов: $2 + 3 \cdot k$. Такое выражение называется выражением с переменной.

### Определение. Выражения с переменными
При решении различных задач получают записи, которые состоят из:
* чисел,
* знаков действий,
* скобок,
* переменных, обозначенных буквами.
Такие записи называют выражениями с переменными.

### Определение. Значение выражения с переменными
Если в выражение с переменными вместо переменных подставить их значения — числа, то получится числовое выражение. Его значение называется значением выражения с переменными при данных значениях переменных.

## Правила и алгоритмы
### Правило. Упрощение выражений с переменными
Применяются распределительный, переместительный и сочетательный законы умножения.

## Ключевые разобранные задания учебника
### Пример 1. Пакет сока стоит 3 р. Сколько рублей должен заплатить покупатель, если он купил коробку печенья за 2 р. и: а) 1 пакет сока; б) 2 пакета сока; в) 3 пакета сока?
Показывает, как формируется выражение с переменной из числовых выражений, когда одна из величин изменяется.

### Пример 2. Один килограмм груш стоит $x$ р., а килограмм моркови — $y$ р. Чему равна стоимость двух килограммов груш и трёх килограммов моркови вместе?
Показывает пример выражения с двумя переменными.

### Пример 3. Найдите значение выражения $1050 - m : 7$, если $m = 105$.
Показывает, как найти значение выражения с одной переменной, подставив её числовое значение.

### Пример 4. Найдите значение выражения $a : 5 + 16 \cdot k$ при $a = 245$, $k = 8$.
Показывает, как найти значение выражения с двумя переменными, подставив их числовые значения.

### Пример 5. Упростите выражение: а) $2 \cdot x + 7 \cdot x$; б) $10 \cdot a - 3 \cdot a$; в) $10 \cdot 3 \cdot x$; г) $4 \cdot x \cdot 6$.
Показывает применение распределительного, переместительного и сочетательного законов умножения для упрощения выражений с переменными.

### Пример 6. Собранные в своём саду яблоки фермер разложил в $k$ ящиков по 9 кг и в $m$ ящиков по 10 кг. Сколько килограммов яблок собрал фермер?
Показывает, как составить выражение с переменными для решения текстовой задачи.

## Замечания учебника
### Проверяем себя
а) Выражения с переменными состоят из **чисел, знаков действий, скобок, переменных, обозначенных буквами**.
б) Если в выражение с переменными вместо **переменных** подставить их **значения**, то получится **числовое выражение**. Его значение называется **значением выражения с переменными** при данных значениях **переменных**.
