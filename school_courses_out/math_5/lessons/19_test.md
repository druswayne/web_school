# Тест по теории. Занятие 19. Уравнение

**Заданий:** 10  
**Формат:** 4 варианта ответа (а–г). Верных может быть один или несколько. Если в условии сказано «Выберите все верные ответы» — отметьте все подходящие; иначе верный один.

Тест проверяет определения, формулы и правила теории этого занятия.

## Т1. *(Определение уравнения)*

Что называется уравнением?

а) Равенство, содержащее переменную
б) Любое числовое выражение без знака равенства
в) Неравенство, содержащее переменную
г) Равенство только с натуральными числами

## Т2. *(Части уравнения)*

Выберите все верные ответы. Какие утверждения верны об уравнении?

а) Выражение слева от знака равенства называется левой частью
б) Выражение справа от знака равенства называется правой частью
в) Уравнение обязательно содержит знак равенства
г) Переменная обязательно обозначается буквой x

## Т3. *(Корень уравнения)*

Что называется корнем уравнения?

а) Любое число, записанное рядом с переменной
б) Значение переменной, при котором получается верное числовое равенство
в) Число, стоящее справа от знака равенства
г) Всегда только натуральное число

## Т4. *(Решение уравнения)*

Что значит решить уравнение?

а) Найти только первое подходящее число
б) Перенести переменную в левую часть
в) Найти все корни уравнения или доказать, что оно корней не имеет
г) Заменить переменную любой буквой

## Т5. *(Неизвестное слагаемое)*

Какая формула верна для уравнения a + x = b?

а) x = a + b
б) x = b - a
в) x = a - b
г) x = b : a

## Т6. *(Компоненты вычитания)*

Выберите все верные правила нахождения неизвестного компонента вычитания.

а) В уравнении x - a = b неизвестное уменьшаемое находят сложением: x = b + a
б) В уравнении a - x = b неизвестное вычитаемое находят вычитанием: x = a - b
в) В уравнении x - a = b неизвестное уменьшаемое находят вычитанием: x = b - a
г) В уравнении a - x = b неизвестное вычитаемое находят сложением: x = a + b

## Т7. *(Умножение и деление)*

Выберите все верные формулы.

а) Если a · x = b, то x = b : a
б) Если x : a = b, то x = a · b
в) Если a : x = b, то x = a · b
г) Если a · x = b, то x = a : b

## Т8. *(Неизвестный делитель)*

Какая формула верна для уравнения a : x = b?

а) x = a · b
б) x = b : a
в) x = a : b
г) x = a + b

## Т9. *(Порядок решения)*

Выберите все верные утверждения о решении уравнений с несколькими действиями.

а) Сначала устанавливают порядок выполнения действий
б) Последнее выполненное действие отменяют первым
в) Скобки при решении уравнения можно не учитывать
г) Каждый шаг должен упрощать уравнение

## Т10. *(Проверка корня)*

Как правильно проверить найденный корень уравнения?

а) Подставить найденное значение в исходное уравнение и проверить равенство
б) Подставить найденное значение только в последний промежуточный шаг
в) Сравнить найденное число с правой частью уравнения
г) Проверить только знак найденного числа
