# Тест по теории. Занятие 8. Сложение и вычитание натуральных чисел

**Заданий:** 10  
**Формат:** 4 варианта ответа (а–г). Верных может быть один или несколько. Если в условии сказано «Выберите все верные ответы» — отметьте все подходящие; иначе верный один.

Тест проверяет определения, формулы и правила теории этого занятия.

## Т1. *(слагаемые и сумма)*

В записи a + b = c какие утверждения верны? Выберите все верные ответы.

а) a и b — слагаемые
б) c — сумма
в) a — разность
г) b — уменьшаемое

## Т2. *(переместительный закон)*

Какая формула выражает переместительный закон сложения?

а) a + b = b + a
б) (a + b) + c = a + (b + c)
в) a - b = b - a
г) a + 0 = 0

## Т3. *(сочетательный закон)*

Какая формула выражает сочетательный закон сложения?

а) a + b = b + a
б) (a + b) + c = a + (b + c)
в) a - b = b - a
г) a - 0 = 0

## Т4. *(правило письменного сложения)*

Какие правила относятся к письменному сложению многозначных чисел? Выберите все верные ответы.

а) Единицы записывают под единицами, десятки — под десятками
б) Сложение выполняют начиная с единиц
в) При получении десятка в разряде его переносят в следующий разряд
г) Сначала складывают только цифры старшего разряда, не учитывая переносы

## Т5. *(разность)*

Какое утверждение правильно определяет разность двух чисел?

а) Разность — это результат сложения двух чисел
б) Разность — это такое число, которое в сумме с вычитаемым даёт уменьшаемое
в) Разность — это число, которое всегда больше уменьшаемого
г) Разность — это второе слагаемое суммы

## Т6. *(компоненты вычитания)*

В записи a - b = c какие утверждения верны? Выберите все верные ответы.

а) a — уменьшаемое
б) b — вычитаемое
в) c — разность
г) c — сумма

## Т7. *(свойства нуля)*

Какие равенства выражают свойства нуля и равных чисел? Выберите все верные ответы.

а) a + 0 = a
б) a - 0 = a
в) a - a = 0
г) a + 0 = 0

## Т8. *(неизвестное слагаемое)*

Если x + b = c, какое правило используют для нахождения неизвестного слагаемого?

а) x = c + b
б) x = c - b
в) x = b - c
г) x = b + c

## Т9. *(неизвестные компоненты вычитания)*

Какие правила нахождения неизвестных компонентов вычитания верны? Выберите все верные ответы.

а) Если x - b = c, то x = c + b
б) Если a - x = c, то x = a - c
в) Если x - b = c, то x = c - b
г) Если a - x = c, то x = a + c

## Т10. *(проверка вычитания)*

Как выполняют проверку результата вычитания a - b = c?

а) Складывают уменьшаемое и вычитаемое
б) Из разности вычитают вычитаемое
в) К разности прибавляют вычитаемое и получают уменьшаемое
г) Из уменьшаемого вычитают разность и получают сумму
