# Тест по теории. Занятие 21. Решение задач с помощью уравнений

**Заданий:** 10  
**Формат:** 4 варианта ответа (а–г). Верных может быть один или несколько. Если в условии сказано «Выберите все верные ответы» — отметьте все подходящие; иначе верный один.

Тест проверяет определения, формулы и правила теории этого занятия.

## Т1. *(Определение уравнения)*

Что называется уравнением?

а) Любое числовое выражение с переменной
б) Равенство, содержащее переменную
в) Неравенство с двумя числами
г) Любая запись, содержащая знак сложения

## Т2. *(Корень уравнения)*

Выберите все верные ответы. Корнем уравнения называется:

а) значение переменной, при котором уравнение превращается в верное числовое равенство
б) любое число, записанное рядом с переменной
в) число, которое удовлетворяет уравнению после подстановки
г) только положительное значение переменной

## Т3. *(Решение уравнения)*

Что значит решить уравнение?

а) Найти только первое найденное значение переменной
б) Упростить левую часть уравнения
в) Найти все корни уравнения или доказать, что корней нет
г) Заменить переменную любым числом

## Т4. *(Алгоритм решения задачи)*

Какое действие выполняют после обозначения неизвестной величины через x и выражения остальных величин через x?

а) Составляют уравнение по условию задачи
б) Сразу записывают ответ без вычислений
в) Заменяют x на единицу измерения
г) Умножают все величины на x

## Т5. *(Выбор неизвестного)*

Выберите все верные утверждения о выборе неизвестной величины.

а) Через x часто удобно обозначать меньшую величину
б) Через x всегда нужно обозначать только большую величину
в) Можно обозначить через x величину, о которой спрашивается, если остальные правильно выразить через x
г) Выбор неизвестного не влияет на выражение остальных величин

## Т6. *(Разность величин)*

Одна величина на b больше другой, а их сумма равна a. Какое уравнение можно составить, если меньшую величину обозначить через x?

а) x + (x + b) = a
б) x + (x - b) = a
в) bx + x = a
г) x + b = a

## Т7. *(Кратное сравнение)*

Выберите все верные записи для утверждения: одна величина в k раз больше другой, если меньшую величину обозначили через x.

а) Большая величина равна kx
б) Большая величина равна x + k
в) При известной сумме величин можно составить уравнение x + kx = a
г) Большая величина равна x - k

## Т8. *(Смысл выражений)*

Какая запись соответствует утверждению: одна величина в 5 раз меньше другой, если большую величину обозначили через x?

а) x - 5
б) x + 5
в) 5x
г) x : 5

## Т9. *(Основная схема)*

Какая последовательность отражает основной способ решения текстовой задачи с помощью уравнения?

а) Ответ → условие задачи → уравнение
б) Условие задачи → уравнение → ответ
в) Уравнение → условие задачи → проверка единиц
г) Известные данные → ответ без уравнения

## Т10. *(Проверка решения)*

Выберите все действия, которые выполняют после нахождения значения x при решении текстовой задачи. Выберите все верные ответы.

а) Подставляют найденное значение в уравнение
б) Проверяют, получилось ли верное равенство
в) Проверяют соответствие ответа смыслу задачи и единицам измерения
г) Обязательно заменяют найденное значение на противоположное число
