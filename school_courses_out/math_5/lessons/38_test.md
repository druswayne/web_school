# Тест по теории. Занятие 38. Среднее арифметическое нескольких чисел

**Заданий:** 10  
**Формат:** 4 варианта ответа (а–г). Верных может быть один или несколько. Если в условии сказано «Выберите все верные ответы» — отметьте все подходящие; иначе верный один.

Тест проверяет определения, формулы и правила теории этого занятия.

## Т1. *(Определение среднего арифметического)*

Что называется средним арифметическим нескольких чисел?

а) Произведение чисел, делённое на их количество
б) Частное от деления суммы чисел на количество слагаемых
в) Сумма чисел, умноженная на их количество
г) Разность наибольшего и наименьшего чисел

## Т2. *(Формула среднего арифметического)*

Какая формула задаёт среднее арифметическое n чисел a₁, a₂, …, aₙ?

а) a₁ + a₂ + … + aₙ
б) (a₁ + a₂ + … + aₙ) · n
в) (a₁ + a₂ + … + aₙ) : n
г) n : (a₁ + a₂ + … + aₙ)

## Т3. *(Алгоритм нахождения среднего)*

Выберите все верные утверждения о нахождении среднего арифметического.

а) Сначала находят сумму всех данных чисел.
б) Сумму делят на количество чисел.
в) Сумму делят на сумму данных чисел.
г) Количество повторений числа учитывают столько раз, сколько это число встречается.

## Т4. *(Границы среднего)*

Какое свойство среднего арифметического верно для нескольких чисел?

а) Оно всегда больше наибольшего из данных чисел.
б) Оно всегда меньше наименьшего из данных чисел.
в) Оно не меньше наименьшего и не больше наибольшего из данных чисел.
г) Оно обязательно совпадает с одним из данных чисел.

## Т5. *(Среднее арифметическое дробей)*

Выберите все верные правила нахождения среднего арифметического дробей.

а) Сначала складывают дроби, затем сумму делят на количество дробей.
б) Перед действиями смешанные числа удобно преобразовать в неправильные дроби.
в) При делении дроби на натуральное число умножают её на обратную дробь.
г) Для нахождения среднего достаточно усреднить отдельно целые и дробные части смешанных чисел.

## Т6. *(Скобки в формуле)*

Какое равенство правильно выражает среднее арифметическое двух чисел a и b?

а) (a + b) : 2
б) a + b : 2
в) (a : 2) + b
г) a + (b : 2)

## Т7. *(Восстановление суммы)*

Как найти сумму чисел, если известно их среднее арифметическое и количество чисел?

а) Среднее арифметическое разделить на количество чисел
б) Среднее арифметическое умножить на количество чисел
в) Из количества чисел вычесть среднее арифметическое
г) Среднее арифметическое возвести в степень, равную количеству чисел

## Т8. *(Неизвестное число)*

Среднее арифметическое двух чисел равно m, одно из чисел равно a. Какая формула задаёт второе число b?

а) b = m − a
б) b = m + a
в) b = 2m − a
г) b = 2a − m

## Т9. *(Средняя скорость)*

Выберите все верные формулы, относящиеся к средней скорости и пути.

а) vср = Sобщ : tобщ
б) S = vt
в) vср = (v₁ + v₂) : 2 для любых участков пути
г) Sобщ — это сумма путей на всех участках движения.

## Т10. *(Средняя скорость и среднее арифметическое)*

Какое утверждение о средней скорости движения верно?

а) Среднюю скорость всегда находят как среднее арифметическое скоростей на участках.
б) Среднюю скорость находят делением общего пути на общее время движения.
в) Среднюю скорость находят делением общего времени на общий путь.
г) Средняя скорость не зависит от продолжительности движения на участках.
