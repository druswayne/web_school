# Тест по теории. Занятие 39. Линейные и столбчатые диаграммы

**Заданий:** 10  
**Формат:** 4 варианта ответа (а–г). Верных может быть один или несколько. Если в условии сказано «Выберите все верные ответы» — отметьте все подходящие; иначе верный один.

Тест проверяет определения, формулы и правила теории этого занятия.

## Т1. *(Столбчатая диаграмма)*

Что характеризует высота столбца на столбчатой диаграмме?

а) Ширину столбца
б) Значение исследуемой величины
в) Количество делений на горизонтальной оси
г) Порядковый номер объекта

## Т2. *(Линейная диаграмма)*

Как строят линейную диаграмму?

а) Значения изображают прямоугольниками одинаковой высоты
б) Для каждого значения ставят точку и соединяют соседние точки отрезками
в) Все значения записывают только в таблицу
г) Точки соединяют в произвольном порядке

## Т3. *(Чтение диаграммы)*

Выберите все верные ответы. Что необходимо определить перед считыванием значений с диаграммы?

а) Что обозначено по горизонтальной оси
б) Что показывает вертикальная ось
в) Цену деления шкалы
г) Только ширину самого высокого столбца

## Т4. *(Шкала диаграммы)*

Какое утверждение о шкале диаграммы является верным?

а) Всегда одно деление шкалы соответствует одной единице
б) Цена деления определяется по значениям, указанным на шкале
в) Шкалу можно не учитывать, если столбцы имеют одинаковую ширину
г) Цена деления зависит от названия объекта

## Т5. *(Построение столбцов)*

Выберите все верные ответы. Какие требования предъявляют к столбцам столбчатой диаграммы?

а) Столбцы должны иметь одинаковую ширину
б) Высота каждого столбца должна соответствовать значению величины
в) Высота всех столбцов должна быть одинаковой
г) Масштаб можно выбирать произвольно после построения столбцов

## Т6. *(Масштаб)*

Как вычисляют высоту столбца, если k единиц величины изображают отрезком высотой 1 см, а значение величины равно L?

а) h = L + k
б) h = k : L
в) h = L : k
г) h = L · k

## Т7. *(Среднее арифметическое)*

Какая формула задаёт среднее арифметическое чисел x₁, x₂, ..., xₘ?

а) x̄ = x₁ + x₂ + ... + xₘ
б) x̄ = (x₁ + x₂ + ... + xₘ) : m
в) x̄ = m : (x₁ + x₂ + ... + xₘ)
г) x̄ = x₁ · x₂ · ... · xₘ : m

## Т8. *(Повторяющиеся значения)*

Выберите все верные ответы. Если значение xᵢ встречается nᵢ раз, то при вычислении среднего арифметического:

а) Значение xᵢ учитывают nᵢ раз
б) Произведение xᵢnᵢ входит в сумму всех значений
в) Повторяющиеся значения можно учитывать только один раз
г) Общее количество данных включает nᵢ

## Т9. *(Доля группы)*

Как находят долю группы от общего числа объектов?

а) Общее число объектов делят на число объектов в группе
б) Число объектов в группе делят на общее число объектов
в) Число объектов в группе умножают на общее число объектов
г) Из общего числа объектов вычитают число объектов в группе

## Т10. *(Сравнение значений)*

Выберите все верные ответы. Какие утверждения о диаграммах правильны?

а) Самый высокий столбец показывает наибольшее значение
б) Самая высокая точка линейной диаграммы соответствует наибольшему значению
в) Одинаковая высота столбцов означает одинаковые значения
г) Самый высокий столбец обязательно соответствует самому важному объекту
