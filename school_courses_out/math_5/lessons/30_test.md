# Тест по теории. Занятие 30. Деление дробных чисел

**Заданий:** 10  
**Формат:** 4 варианта ответа (а–г). Верных может быть один или несколько. Если в условии сказано «Выберите все верные ответы» — отметьте все подходящие; иначе верный один.

Тест проверяет определения, формулы и правила теории этого занятия.

## Т1. *(Взаимно обратные числа)*

Какие числа называются взаимно обратными?

а) Числа, сумма которых равна единице
б) Числа, произведение которых равно единице
в) Числа, разность которых равна единице
г) Числа, частное которых равно единице

## Т2. *(Обратная дробь)*

Выберите все верные ответы. Какое число является обратным дроби a/b, если a ≠ 0 и b ≠ 0?

а) b/a
б) 1/(a/b)
в) a/b
г) a−b

## Т3. *(Обратное натуральное число)*

Как находят число, обратное натуральному числу n?

а) Записывают число n со знаменателем 1 и меняют местами числитель и знаменатель
б) Умножают число n на 1
в) Вычитают число n из единицы
г) Записывают число n со знаменателем 0

## Т4. *(Обратное смешанное число)*

Как правильно найти число, обратное смешанному числу?

а) Поменять местами целую и дробную части
б) Сначала записать смешанное число в виде неправильной дроби, затем поменять местами числитель и знаменатель
в) Поменять местами только числитель и целую часть
г) Разделить целую часть на дробную

## Т5. *(Ноль и обратное число)*

Выберите все верные ответы. Какие утверждения верны?

а) Ноль не имеет обратного числа
б) Обратное число существует для любого ненулевого числа
в) У нуля обратным числом является единица
г) Произведение числа и его обратного числа равно единице, если число не равно нулю

## Т6. *(Деление дробей)*

Какая формула правильно выражает деление дроби a/b на дробь c/d, где b, c и d не равны нулю?

а) a/b : c/d = a/b · c/d
б) a/b : c/d = b/a · d/c
в) a/b : c/d = a/b · d/c
г) a/b : c/d = (a+c)/(b+d)

## Т7. *(Алгоритм деления дробей)*

Выберите все верные действия при делении одной обыкновенной дроби на другую.

а) Делимое оставляют без изменения
б) Знак деления заменяют знаком умножения
в) Делитель заменяют обратным ему числом
г) Переворачивают обе дроби

## Т8. *(Деление на натуральное число)*

Какая формула верна для деления дроби a/b на натуральное число n?

а) a/b : n = an/b
б) a/b : n = a/(bn)
в) a/b : n = (a+n)/(b+n)
г) a/b : n = n/(ab)

## Т9. *(Деление смешанных чисел)*

Каков правильный порядок действий при делении смешанных чисел?

а) Сначала отдельно разделить целые и дробные части
б) Сначала сложить целые части, затем разделить дробные
в) Записать смешанные числа в виде неправильных дробей, затем выполнить деление дробей
г) Перевернуть только дробную часть делителя

## Т10. *(Формулы движения)*

Выберите все верные формулы для величин, связанных с движением: скорости v, пути s и времени t.

а) v = s : t
б) s = v · t
в) t = s : v
г) v = s · t
