# Тест по теории. Занятие 14. Делители числа. Кратные числа

**Заданий:** 10  
**Формат:** 4 варианта ответа (а–г). Верных может быть один или несколько. Если в условии сказано «Выберите все верные ответы» — отметьте все подходящие; иначе верный один.

Тест проверяет определения, формулы и правила теории этого занятия.

## Т1. *(Определение делителя)*

Какое утверждение правильно определяет делитель числа?

а) Делитель — это число, которое получается в результате деления.
б) Делитель — это число, на которое делят другое число без остатка.
в) Делитель — это число, которое делится на данное число с остатком.
г) Делитель — это произведение двух чисел.

## Т2. *(Связь делителя и кратного)*

Если число a делится на число b без остатка, выберите все верные ответы.

а) b является делителем числа a.
б) a является кратным числа b.
в) a является делителем числа b.
г) b является кратным числа a.

## Т3. *(Формула делимости)*

Какая формула выражает деление числа a на число b без остатка?

а) a = b + c
б) a = b · c
в) b = a · c
г) a = c − b

## Т4. *(Проверка делителя)*

Как правильно проверить, является ли число b делителем числа a?

а) Разделить b на a и проверить, что остаток равен нулю.
б) Сложить a и b и проверить, что сумма делится нацело.
в) Разделить a на b и проверить, что остаток равен нулю.
г) Умножить a на b и проверить, что произведение больше a.

## Т5. *(Делители натурального числа)*

Выберите все верные утверждения о делителях натурального числа.

а) Единица всегда является делителем натурального числа.
б) Само натуральное число всегда является своим делителем.
в) Делителей любого натурального числа бесконечно много.
г) Делитель обязательно больше числа, которое делят.

## Т6. *(Определение кратного)*

Какое утверждение правильно определяет кратное числа b?

а) Кратное числа b — это число, которое делится на b без остатка.
б) Кратное числа b — это число, на которое делят b без остатка.
в) Кратное числа b — это любой делитель числа b.
г) Кратное числа b — это число, которое всегда меньше b.

## Т7. *(Запись кратных)*

Как можно записать последовательность натуральных чисел, кратных числу b?

а) b + 1, b + 2, b + 3, ...
б) b · 1, b · 2, b · 3, ...
в) 1 : b, 2 : b, 3 : b, ...
г) b − 1, b − 2, b − 3, ...

## Т8. *(НОД)*

Что называется наибольшим общим делителем двух натуральных чисел?

а) Наименьшее число, которое делится на оба данных числа.
б) Наибольшее число, которое делится на оба данных числа.
в) Наибольший общий делитель двух данных чисел.
г) Наибольшее число, на которое делятся оба данных числа без остатка.

## Т9. *(НОК)*

Выберите все верные утверждения о наименьшем общем кратном.

а) НОК ищут среди общих кратных данных чисел.
б) НОК — это наименьшее натуральное число, которое делится на данные числа без остатка.
в) НОК всегда меньше каждого из данных чисел.
г) Общих кратных двух натуральных чисел бесконечно много.

## Т10. *(НОД и НОК)*

Какое утверждение правильно различает НОД и НОК?

а) НОД ищут среди общих кратных, а НОК — среди общих делителей.
б) НОД и НОК обозначают одно и то же число.
в) НОД ищут среди общих делителей, а НОК — среди общих кратных.
г) НОД всегда больше НОК.
