# Тест по теории. Занятие 11. Деление с остатком

**Заданий:** 10  
**Формат:** 4 варианта ответа (а–г). Верных может быть один или несколько. Если в условии сказано «Выберите все верные ответы» — отметьте все подходящие; иначе верный один.

Тест проверяет определения, формулы и правила теории этого занятия.

## Т1. *(Формула деления с остатком)*

Какая формула правильно описывает деление с остатком?

а) a = q + b + r
б) a = q · b + r
в) a = q · r + b
г) a = b · r − q

## Т2. *(Обозначения)*

Выберите все верные ответы. В записи a = q · b + r буквой a обозначают:

а) делимое
б) делитель
в) неполное частное
г) число, которое делят

## Т3. *(Смысл остатка)*

Что называют остатком при делении с остатком?

а) Число полных групп
б) Число, на которое делят
в) То, что остаётся после составления наибольшего числа полных групп
г) Результат сложения делимого и делителя

## Т4. *(Условие для остатка)*

Какое условие обязательно выполняется для остатка r при делении на делитель b?

а) r > b
б) r = b
в) r < b
г) r всегда больше нуля

## Т5. *(Возможные остатки)*

Выберите все верные ответы. Какие остатки могут получиться при делении натуральных чисел на 6?

а) 0
б) 5
в) 6
г) 3

## Т6. *(Нахождение делимого)*

Как найти делимое, если известны делитель, неполное частное и остаток?

а) Неполное частное разделить на делитель и прибавить остаток
б) Делитель умножить на неполное частное и прибавить остаток
в) Делитель умножить на остаток и вычесть неполное частное
г) Неполное частное сложить с делителем и остатком

## Т7. *(Деление без остатка)*

Выберите все верные ответы. Что означает остаток 0 при делении?

а) Число разделилось нацело
б) Все группы получились полными
в) Остаток не считается остатком
г) В формуле a = q · b + r значение r равно 0

## Т8. *(Неполное частное)*

Что показывает неполное частное при делении с остатком?

а) Количество полных групп
б) Количество предметов, оставшихся после деления
в) Размер остатка
г) Количество предметов в одной группе

## Т9. *(Алгоритм деления)*

Какое действие выполняют, чтобы найти остаток после определения неполного частного?

а) К делимому прибавляют произведение делителя и частного
б) Из делимого вычитают произведение делителя и неполного частного
в) Делимое делят на остаток
г) Из делителя вычитают неполное частное

## Т10. *(Дополнительная группа)*

Выберите все верные ответы. Если при распределении предметов по одинаковым группам получился ненулевой остаток, то:

а) Для полностью заполненных групп берут только неполное частное
б) Для размещения всех предметов может потребоваться ещё одна группа
в) Ненулевой остаток всегда означает ошибку в делении
г) Количество групп для размещения всех предметов может быть на одну больше неполного частного
