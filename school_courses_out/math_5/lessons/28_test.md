# Тест по теории. Занятие 28. Сложение и вычитание смешанных чисел

**Заданий:** 10  
**Формат:** 4 варианта ответа (а–г). Верных может быть один или несколько. Если в условии сказано «Выберите все верные ответы» — отметьте все подходящие; иначе верный один.

Тест проверяет определения, формулы и правила теории этого занятия.

## Т1. *(Состав смешанного числа)*

Что представляет собой смешанное число?

а) Сумму двух правильных дробей
б) Целую и дробную части
в) Произведение целого числа и дроби
г) Только неправильную дробь

## Т2. *(Сложение частей)*

Выберите все верные ответы. Как складывают смешанные числа?

а) Отдельно складывают целые части и дробные части
б) Складывают знаменатели дробных частей
в) При одинаковых знаменателях складывают числители, оставляя знаменатель прежним
г) Целые части всегда превращают в дроби с общим знаменателем

## Т3. *(Формула сложения)*

Какая формула верна для сложения смешанных чисел с одинаковыми знаменателями дробных частей?

а) a m/n + b k/n = (a + b) + (m + k)/n
б) a m/n + b k/n = (a + b) + (m + k)/(2n)
в) a m/n + b k/n = (a + b) + (m + k)/(mn)
г) a m/n + b k/n = (a + b) + (m + k)/(m + n)

## Т4. *(Неправильная дробь)*

Что делают, если после сложения дробных частей получилась неправильная дробь?

а) Оставляют её без изменений в окончательном ответе
б) Заменяют её нулём
в) Выделяют из неё целую часть и прибавляют её к целой части результата
г) Умножают её числитель на знаменатель

## Т5. *(Целое и дробь)*

Какая запись правильно выражает сумму целого числа и правильной дроби?

а) a + m/n = (a + m)/n
б) a + m/n = a m/n
в) a + m/n = am/n
г) a + m/n = a/(m + n)

## Т6. *(Вычитание из единицы)*

Выберите все верные ответы. Какие записи соответствуют правилу вычитания правильной дроби из единицы?

а) 1 - m/n = n/n - m/n
б) 1 - m/n = (1 - m)/n
в) 1 - m/n = (n - m)/n
г) Единицу представляют дробью со знаменателем n

## Т7. *(Вычитание дроби из целого)*

Какая формула описывает вычитание правильной дроби из целого числа?

а) a - m/n = a - (1 - m/n)
б) a - m/n = (a - 1) + (1 - m/n)
в) a - m/n = (a - 1) - (1 - m/n)
г) a - m/n = a + (1 - m/n)

## Т8. *(Разные знаменатели)*

Что необходимо сделать при сложении или вычитании смешанных чисел с разными знаменателями дробных частей?

а) Сложить или вычесть знаменатели
б) Привести дробные части к общему знаменателю
в) Привести к общему знаменателю целые части
г) Сложить числители, не изменяя знаменатели

## Т9. *(Занимание единицы)*

Выберите все верные утверждения о вычитании смешанных чисел с заниманием единицы.

а) Единицу занимают из целой части уменьшаемого
б) Занятую единицу представляют дробью со знаменателем дробной части
в) После занимания целая часть уменьшаемого увеличивается на единицу
г) К дробной части уменьшаемого прибавляют преобразованную единицу

## Т10. *(Вычитание смешанного числа из целого)*

Как правильно вычитать смешанное число из целого числа?

а) Из целого числа вычитают только целую часть смешанного числа
б) Из целого числа вычитают дробную часть, не учитывая целую
в) Сначала вычитают целую часть, затем из полученного числа вычитают дробную часть
г) Целое число складывают с дробной частью смешанного числа
