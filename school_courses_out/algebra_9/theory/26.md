# § 19. Сумма бесконечно убывающей геометрической прогрессии

**Страницы учебника:** 255–262
**Глава:** Прогрессии

## Определения
### Определение. Бесконечно убывающей геометрической прогрессией
Бесконечно убывающей геометрической прогрессией называется такая бесконечная геометрическая прогрессия, у которой знаменатель $|q| < 1$.

## Формулы
### Сумма бесконечно убывающей геометрической прогрессии
$$S = \frac{b_1}{1-q}, |q|<1$$

## Правила и алгоритмы
### Чтобы записать бесконечную периодическую десятичную дробь в виде обыкновенной дроби, нужно:
1. Представить число в виде суммы разрядных слагаемых.
2. Выделить сумму бесконечно убывающей геометрической прогрессии.
3. Указать первый член $b_1$ и найти знаменатель этой прогрессии $q$.
4. Найти сумму бесконечно убывающей геометрической прогрессии по формуле $S = \frac{b_1}{1-q}$.
5. Вычислить сумму первых слагаемых и найденного значения суммы бесконечно убывающей геометрической прогрессии.

## Ключевые разобранные задания учебника
### Пример 1. (стр. 256)
Рассмотрение бесконечной периодической десятичной дроби $0,(7) = 0,7777...$ и ее представление в виде суммы разрядных слагаемых, которые образуют бесконечно убывающую геометрическую прогрессию.

### Пример 2. (стр. 257)
Вычисление суммы бесконечно убывающей геометрической прогрессии для $0,(7)$ по формуле $S = \frac{b_1}{1-q}$.

### Пример 3. (стр. 257)
Запись бесконечной периодической десятичной дроби $2,4(15)$ в виде обыкновенной дроби с использованием алгоритма.

### Пример 4. (стр. 258)
Определение, является ли геометрическая прогрессия $b_1 = -36, b_2 = 6$ бесконечно убывающей.

### Пример 5. (стр. 259)
Определение, является ли бесконечно убывающей геометрическая прогрессия:
а) $4; \frac{4}{3}; \frac{4}{9}; \frac{4}{27}; ...;$
б) $1; -\frac{1}{3}; \frac{1}{9}; -\frac{1}{27}; ...;$
в) $2; -4; 8; -16; ... ?$

### Пример 6. (стр. 259)
Нахождение суммы бесконечно убывающей геометрической прогрессии, в которой $b_1 = 5$, $q = -\frac{1}{2}$.

### Пример 7. (стр. 259)
Нахождение первого члена бесконечно убывающей геометрической прогрессии, если $S = 90, q = 0,1$.

### Пример 8. (стр. 259)
Запись бесконечной периодической десятичной дроби $15,2(3)$ в виде обыкновенной дроби с использованием алгоритма.

## Упражнения параграфа

4.284. Какую формулу нужно применить, чтобы найти сумму бесконечно убывающей геометрической прогрессии $(b_n)$ со знаменателем $q$? Найдите эту сумму, если:
а) $b_1 = 12, q = \frac{1}{4}$;
б) $b_1 = -25, q = -\frac{2}{5}$;
в) $b_1 = 21, q = -\frac{1}{3}$;
г) $b_1 = -0,1, q = 0,9$.
4.285. Составьте план решения и найдите сумму бесконечно убывающей геометрической прогрессии:
а) $100; 10; 1; ...$;
б) $0,2; 0,02; 0,002; ...$;
в) $9; -4,5; 2,25; ...$;
г) $-3; -2; -\frac{4}{3}; ...$.
4.286. Найдите сумму, слагаемыми которой являются последовательные члены геометрической прогрессии:
а) $1 + \frac{1}{4} + \frac{1}{16} + \frac{1}{64} + ...$;
б) $3 - \frac{3}{5} + \frac{3}{25} - \frac{3}{125} + ...$.
4.287. Примените алгоритм для представления в виде обыкновенной дроби числа:

г) $14,(31)$;
д) $6,3(8)$;
е) $10,1(26)$.
4.288. Используйте формулу суммы бесконечно убывающей геометрической прогрессии и найдите первый член бесконечно убывающей геометрической прогрессии, у которой:
а) $S = 72, q = \frac{2}{9}$;
б) $S = 8, q = -\frac{3}{4}$.
4.289. Найдите знаменатель бесконечно убывающей геометрической прогрессии, если:

в) $1; \frac{1}{\sqrt{3}}; \frac{1}{3}; ...$.

4.292. Найдите сумму бесконечно убывающей геометрической прогрессии, если:
