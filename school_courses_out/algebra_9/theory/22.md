# § 15. Арифметическая прогрессия

**Страницы учебника:** 212–224
**Глава:** 4

## Определения
### Определение. Арифметическая прогрессия
Арифметической прогрессией называется числовая последовательность, каждый член которой, начиная со второго, равен предыдущему члену, сложенному с одним и тем же для данной последовательности числом, т. е.
$$a_{n+1} = a_n + d, \text{ где } n \in \mathbb{N}, d \in \mathbb{R}.$$
Число $d$ называется *разностью арифметической прогрессии*.

## Свойства
### Характеристическое свойство арифметической прогрессии
Числовая последовательность является арифметической прогрессией тогда и только тогда, когда каждый ее член, начиная со второго, равен среднему арифметическому предыдущего и последующего членов: $a_n = \frac{a_{n-1}+a_{n+1}}{2}$.

## Формулы
### Формула $n$-го члена арифметической прогрессии
$$a_n = a_1 + (n-1)d.$$

## Ключевые разобранные задания учебника
### Пример 1.
**Условие:** Последовательность $(a_n)$ — арифметическая прогрессия, $a_1 = 2$, $d = 2,5$. Найдите 100-й член прогрессии.
**Что показывают:** Применение формулы $n$-го члена для нахождения конкретного члена прогрессии.

### Пример 2.
**Условие:** Последовательность $(a_n)$ — арифметическая прогрессия, $a_1 = 3$, $d = 2,5$. Является ли членом этой прогрессии число: а) 168; б) 201?
**Что показывают:** Использование формулы $n$-го члена для определения, является ли данное число членом прогрессии, и нахождения его номера.

### Пример 3.
**Условие:** Проверьте, является ли арифметической прогрессией последовательность, заданная формулой $a_n = 2n + 7$.
**Что показывают:** Применение характеристического свойства арифметической прогрессии для проверки, является ли последовательность арифметической.

### Определение арифметической прогрессии (примеры)
1. **Условие:** Последовательность 2; 12; 22; ... является арифметической прогрессией. Продолжите последовательность.
**Что показывают:** Нахождение разности прогрессии и продолжение последовательности по определению.

2. **Условие:** Известны члены арифметической прогрессии: $a_6 = -2$; $a_7 = 3$. Найдите разность этой прогрессии.
**Что показывают:** Нахождение разности прогрессии по двум последовательным членам.

### Формула n-го члена арифметической прогрессии (примеры)
3. **Условие:** Последовательность $(a_n)$ — арифметическая прогрессия. Найдите двадцатый член прогрессии, если $a_1 = 3$, $d = 1,6$.
**Что показывают:** Прямое применение формулы $n$-го члена.

4. **Условие:** Запишите формулу n-го члена для арифметической прогрессии $-15,5$; $-14,9$; $-14,3$; ... и найдите ее двадцатый член.
**Что показывают:** Вывод формулы $n$-го члена по первым членам и последующее вычисление конкретного члена.

5. **Условие:** В арифметической прогрессии $(a_n)$ известно, что $a_1 = -5,6$; $a_2 = -4,8$. Число 16 является членом этой прогрессии. Найдите его номер.
**Что показывают:** Нахождение номера члена прогрессии по его значению, первому члену и разности.

6. **Условие:** В арифметической прогрессии $a_6 = 8$, $a_{10} = 16$. Найдите разность прогрессии и ее первый член.
**Что показывают:** Составление и решение системы уравнений для нахождения первого члена и разности прогрессии по двум произвольным членам.
