## Ключевые разобранные задания учебника
**1. Найдите значение функции:**
а) $f(x) = -x^2 - 1$;
б) $g(x) = \frac{2x}{x^3 + 4}$;
в) $h(x) = \sqrt{x^2 + 4}$, если значение аргумента равно $-2$.
*Показывает, как подставлять значение аргумента в формулу функции для нахождения значения функции.*

**2. Найдите, при каком значении аргумента значение функции:**
а) $f(x) = x^2 - 8$;
б) $g(x) = \frac{8}{x}$;
в) $h(x) = |x|$ равно $1$.
*Показывает, как находить значение аргумента, если известно значение функции, решая соответствующее уравнение.*

**3. Функция $g(x) = \frac{4}{x - 3}$ задана аналитически на множестве $D = \{1; 2; 4; 5; 7\}$. Задайте ее:**
а) таблицей;
б) графически.
*Показывает способы задания функции: аналитический, табличный и графический.*

**4. Найдите $D(f)$ и $E(f)$ по графику функции, изображенному на рисунке 5.**
*Показывает, как определять область определения ($D(f)$) и множество значений ($E(f)$) функции по её графику.*

**5. Найдите область определения функции:**
а) $g(x) = \frac{5x-1}{1-3x}$;
б) $p(x) = \frac{2x+3}{x+2} + \frac{9x-2}{x}$;
в) $f(x) = \sqrt{x^2-5x+4}$;
г) $h(x) = \frac{5}{\sqrt{x-4}} + \sqrt{13-2x}$.
*Показывает, как находить область определения функции, учитывая ограничения на знаменатель дроби (не равен нулю) и подкоренное выражение (неотрицательно).*

**6. Найдите множество значений функции:**
а) $f(x) = |x|+4$;
б) $g(x) = -x^2 + 6x - 2$;
в) $h(x) = \sqrt{x+3} - 5$.
*Показывает, как находить множество значений функции, используя свойства модуля, параболы и арифметического квадратного корня.*
