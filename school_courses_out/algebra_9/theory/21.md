# § 14. Числовая последовательность

**Страницы учебника:** 205–211
**Глава:** 4. Прогрессии

## Определения
### Определение. Числовой последовательностью
Числовой последовательностью называется функция, определенная на множестве $N$ натуральных чисел, т. е. зависимость, при которой каждому натуральному числу ставится в соответствие единственное действительное число.

## Правила и алгоритмы
*   **Аналитический способ** — это задание последовательности с помощью формулы ее $n$-го члена.
*   **Рекуррентный способ** (от лат. *recurrentis* — возвращающийся) заключается в вычислении следующих членов последовательности по предыдущим.

## Ключевые разобранные задания учебника
### 1. Последовательность $(x_n)$ задана формулой $n$-го члена $x_n = 2n^2 - 1$. Найдите: $x_1$; $x_2$; $x_6$; $x_k$; $x_{k+1}$; $x_{2k+1}$.
Показывает, как находить члены последовательности по формуле $n$-го члена, подставляя вместо $n$ соответствующий номер.

### 2. Последовательность задана формулой $n$-го члена $a_n = 3 - 2n$. Является ли членом этой последовательности число: а) $-2$; б) $-7$?
Показывает, как определить, является ли данное число членом последовательности, путем решения уравнения относительно $n$ и проверки, является ли $n$ натуральным числом.

### 4*. Запишите 5 первых членов последовательности $(a_n)$, если $a_1 = -8$, $a_{n+1} = a_n + 5$.
Показывает, как находить члены последовательности, заданной рекуррентным способом.

### 5*. Запишите несколько первых членов последовательности $(b_n)$, если $b_1 = 8$, $b_{n+1} = -b_n$. Задайте эту последовательность формулой $n$-го члена.
Показывает, как находить члены последовательности, заданной рекуррентным способом, и как вывести формулу $n$-го члена для такой последовательности.

## Замечания учебника
*   Числа, образующие последовательность (значения функции), называются членами последовательности. Они записываются буквами с индексами, обозначающими номер члена последовательности: $f_1$ — первый член последовательности, $f_2$ — второй член последовательности, ..., $f_n$ — $n$-й член последовательности. Последовательность с $n$-м членом $f_n$ обозначается $(f_n)$. Для обозначения последовательности можно использовать любую букву латинского алфафвита. Например, последовательность $(a_n)$ имеет вид $a_1; a_2; ...; a_n; ...$.
*   Чтобы найти некоторый член последовательности с помощью формулы $n$-го члена, нужно вместо $n$ подставить в формулу натуральное число, равное номеру искомого члена (индексу в его обозначении).
*   Последовательность Фибоначчи: $1; 1; 2; 3; 5; ...$ задается рекуррентно $b_1 = 1$; $b_2 = 1$ и $b_{n+2} = b_n + b_{n+1}$.
