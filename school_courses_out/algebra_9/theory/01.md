# § 1. Рациональная дробь

**Страницы учебника:** 11–18
**Глава:** 1. Рациональные выражения

## Определения
### Определение. Рациональная дробь
Дробь, числитель и знаменатель которой — многочлены, называется **рациональной дробью**.

### Определение. Рациональные выражения
Выражения, составленные из чисел, переменных с помощью действий сложения, вычитания, умножения, деления, возведения в натуральную степень, называют рациональными выражениями.

### Определение. Целое рациональное выражение
Если рациональное выражение не содержит деления на выражение с переменными, то оно называется целым рациональным выражением.

### Определение. Дробное рациональное выражение
Рациональное выражение, содержащее деление на выражение с переменными, называют дробным рациональным выражением.

### Определение. Область определения рациональной дроби
Областью определения рациональной дроби является множество всех значений входящих в нее переменных, кроме тех, которые обращают ее знаменатель в нуль.

## Ключевые разобранные задания учебника
### Пример (стр. 11). Задача про туристов
Показывает, как при решении практической задачи получается рациональная дробь.

### Пример (стр. 13). Найдите область определения рациональной дроби
а) $\frac{5x}{x-4}$; б) $\frac{6y-1}{y(y+8)}$; в) $\frac{7a-4}{a^2+9}$.
Показывает нахождение области определения для различных видов рациональных дробей, включая случаи, когда знаменатель не обращается в нуль.

### Пример 1 (стр. 14). Какие из следующих выражений являются рациональными?
а) $6,7z + \frac{2}{3}xy$; б) $2\sqrt{xy}$; в) $\frac{x+y}{x-6}$; г) $4 + \frac{1}{30}x^2y$; д) $\sqrt{2x}$.
Показывает, какие выражения являются рациональными, а какие нет (из-за наличия корня из переменной).

### Пример 2 (стр. 14). Какие из следующих выражений являются дробными рациональными?
а) $0,2x + \frac{x}{3}$; б) $\frac{2x^2-y^4}{x}$; в) $\frac{x-5y}{2x+y}$; г) $\frac{4-y}{3}$; д) $\frac{y+5}{4x-6}$.
Показывает, какие выражения являются дробными рациональными (содержат деление на выражение с переменными).

### Пример 3 (стр. 14). Какие из следующих выражений являются рациональными дробями?
а) $\frac{14c}{15}$; б) $\frac{2x}{x^4+2}$; в) $\frac{6}{p-5}$; г) $\frac{m}{6m^2+3}$; д) $\frac{8}{9c}$.
Показывает примеры рациональных дробей.

### Пример 4 (стр. 14). Найдите значение выражения
а) $\frac{x+3}{x-3}$ при $x=0$; б) $a + \frac{8}{a-1}$ при $a=\frac{1}{2}$; в) $\frac{2m-n}{3m+2n}$ при $m=4, n=-5$.
Показывает подстановку числовых значений в рациональные выражения и вычисление их значений.

### Пример 5 (стр. 15). Найдите область определения рациональной дроби
а) $\frac{x+5}{6-2x}$; б) $\frac{2x-7}{x(x+2)}$; в) $\frac{x+15}{x^2-16}$.
Показывает нахождение области определения рациональных дробей путем исключения значений, обращающих знаменатель в нуль.

### Пример 6 (стр. 15). Найдите область определения рационального выражения
а) $x^3-4x^2+2$; б) $\frac{5}{x-1} + \frac{x+6}{x+3}$.
Показывает нахождение области определения для целого рационального выражения (все действительные числа) и для суммы рациональных дробей (исключение значений, обращающих в нуль любой из знаменателей).

## Упражнения параграфа

1.8. 1.9. Приведите пример значений переменных $a$ и $b$, при которых значение рациональной дроби $\frac{a + 1}{b}$ является: а) целым числом; б) дробным числом; в) отрицательным числом; г) иррациональным числом.
1.10. Найдите значение функции $y = \frac{x^2 - x}{x - 3}$ при значении аргумента, равном: а) $1$; б) $2\frac{1}{3}$; в) $1,5$; г) $\sqrt{2} + 3$. Выберите из этих значений: 1) целые; 2) рациональные; 3) иррациональные.
1.11. Найдите область определения рациональной дроби: а) $\frac{x - 1}{x - 4}$; б) $\frac{3c + 5}{1 - 5c}$; в) $\frac{8m - 5}{m}$; г) $\frac{8}{x(x + 2)}$; д) $\frac{12a + 7}{a^2 - 8a}$; е) $\frac{8b - 1}{(b - 3)(b + 2)}$; ж) $\frac{5y}{y^2 - 9}$; з) $\frac{3a - 1}{a^2 - 7}$; и) $\frac{x + 4}{12}$; к) $\frac{9}{n^2 + 7}$; л) $\frac{6x}{2x^2 + 1}$; м) $\frac{12c - 1}{c^2}$.
1.12. Приведите пример рациональной дроби, областью определения которой является множество всех действительных чисел, кроме: а) числа $5$; б) чисел $-4$ и $2$; в) чисел $0$ и $15$.
1.13. Найдите, при каких значениях переменной имеет смысл выражение: а) $x^2 + 8x - 5$; б) $x + \frac{x-4}{7}$; в) $\frac{x-6}{x} + \frac{5}{x-2}$; г) $\frac{2x-1}{3x+2} - \frac{x-7}{x-4}$; д) $\frac{5}{x^2+3x} + \frac{8}{x-1}$; е) $\frac{9}{x^2-25} + \frac{7}{x^2+16}$.
