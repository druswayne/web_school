# Тест по теории. Занятие 25. Формула суммы n первых членов геометрической прогрессии

**Заданий:** 10  
**Формат:** 4 варианта ответа (а–г). Верных может быть один или несколько. Если в условии сказано «Выберите все верные ответы» — отметьте все подходящие; иначе верный один.

Тест проверяет определения, формулы и правила теории этого занятия.

## Т1. *(формула суммы)*

Какая формула используется для суммы $n$ первых членов геометрической прогрессии при $q \neq 1$?

а) $S_{n} = b_{1}q^{n-1}$
б) $S_{n} = nb_{1}$
в) $S_{n} = \frac{b_{1}(q^{n} - 1)}{q - 1}$
г) $S_{n} = \frac{b_{1}(q^{n-1} - 1)}{q - 1}$

## Т2. *(случай q равен 1)*

Как находят сумму $n$ первых членов геометрической прогрессии, если $q = 1$?

а) $S_{n} = \frac{b_{1}(q^{n} - 1)}{q - 1}$
б) $S_{n} = nb_{1}$
в) $S_{n} = b_{1}q^{n-1}$
г) $S_{n} = \frac{b_{1}}{q^{n-1}}$

## Т3. *(обозначения)*

Выберите все верные ответы. Что обозначают буквы в формуле суммы геометрической прогрессии?

а) $S_{n}$ — сумма $n$ первых членов
б) $b_{1}$ — первый член прогрессии
в) $q$ — знаменатель прогрессии
г) $n$ — значение знаменателя прогрессии

## Т4. *(условие применения)*

При каком условии применяют формулу $S_{n} = \frac{b_{1}(q^{n} - 1)}{q - 1}$?

а) Только при $q = 1$
б) При $q \neq 1$
в) Только при $q > 1$
г) Только при $q < 0$

## Т5. *(знаменатель прогрессии)*

Какая формула позволяет найти знаменатель геометрической прогрессии по двум последовательным членам?

а) $q = \frac{b_{n}}{b_{n+1}}$
б) $q = b_{n+1} - b_{n}$
в) $q = \frac{b_{n+1}}{b_{n}}$
г) $q = b_{n}b_{n+1}$

## Т6. *(формула n-го члена)*

Выберите все верные ответы. Какие формулы связаны с нахождением первого или $n$-го члена геометрической прогрессии?

а) $b_{n} = b_{1}q^{n-1}$
б) $b_{1} = \frac{b_{n}}{q^{n-1}}$
в) $b_{n} = b_{1}q^{n}$
г) $b_{1} = b_{n}q^{n-1}$

## Т7. *(вывод формулы)*

Какое равенство получают после вычитания из равенства $S_{n}q$ равенства $S_{n}$ при выводе формулы суммы?

а) $S_{n}(q + 1) = b_{1}(q^{n} + 1)$
б) $S_{n}(q - 1) = b_{1}(q^{n} - 1)$
в) $S_{n}q = b_{1}(q^{n-1} - 1)$
г) $S_{n}(q - 1) = b_{1}(q^{n-1} - 1)$

## Т8. *(степень в формулах)*

Выберите все верные ответы. Какие утверждения о показателях степени в формулах геометрической прогрессии верны?

а) В формуле суммы содержится $q^{n}$
б) В формуле $n$-го члена содержится $q^{n-1}$
в) В формуле суммы содержится $q^{n-1}$
г) В формуле $n$-го члена содержится $q^{n}$

## Т9. *(процентное изменение)*

б) $q = 1 + \frac{p}{100}$
в) $q = 1 - \frac{p}{100}$
г) $q = 100 - p$

а) Если два последовательных члена отрицательны, их отношение может быть положительным
