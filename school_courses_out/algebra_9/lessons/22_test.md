# Тест по теории. Занятие 22. Арифметическая прогрессия

**Заданий:** 10  
**Формат:** 4 варианта ответа (а–г). Верных может быть один или несколько. Если в условии сказано «Выберите все верные ответы» — отметьте все подходящие; иначе верный один.

Тест проверяет определения, формулы и правила теории этого занятия.

## Т1. *(Определение)*

Что называется арифметической прогрессией?

а) Числовая последовательность, каждый член которой равен предыдущему, умноженному на одно и то же число
б) Числовая последовательность, каждый член которой, начиная со второго, равен предыдущему, сложенному с одним и тем же числом
в) Последовательность, в которой каждый член является средним арифметическим всех предыдущих членов
г) Числовая последовательность, состоящая только из положительных чисел

## Т2. *(Разность прогрессии)*

Выберите все верные ответы. Какие формулы позволяют найти разность арифметической прогрессии?

а) $d = a_{n+1} - a_{n}$
б) $d = a_{n} - a_{n+1}$
в) $d = \frac{a_{n} - a_{1}}{n - 1}$, если $n \neq 1$
г) $d = a_{n+1} + a_{n}$

## Т3. *(Задание прогрессии)*

Какие два значения достаточно задать, чтобы однозначно задать арифметическую прогрессию?

а) Первый член $a_{1}$ и разность $d$
б) Второй член $a_{2}$ и последний член
в) Только первый член $a_{1}$
г) Только разность $d$

## Т4. *(Формула n-го члена)*

Какая формула является формулой $n$-го члена арифметической прогрессии?

а) $a_{n} = a_{1} + nd$
б) $a_{n} = a_{1} + (n - 1)d$
в) $a_{n} = a_{1} + (n + 1)d$
г) $a_{n} = a_{1}n + d$

## Т5. *(Знак разности)*

Выберите все верные ответы о знаке разности арифметической прогрессии.

а) У возрастающей арифметической прогрессии $d > 0$
б) У убывающей арифметической прогрессии $d < 0$
в) Если все члены равны, то $d = 1$
г) Если все члены равны, то $d = 0$

## Т6. *(Соседние члены)*

Какая формула выражает связь двух соседних членов арифметической прогрессии?

а) $a_{n+1} = a_{n} + d$
б) $a_{n+1} = a_{n}d$
в) $a_{n+1} = a_{n} - d$
г) $a_{n} = a_{n+1} + d$

## Т7. *(Характеристическое свойство)*

Выберите все верные формулировки характеристического свойства арифметической прогрессии.

а) Каждый внутренний член равен среднему арифметическому двух соседних членов
б) $a_{n} = \frac{a_{n-1} + a_{n+1}}{2}$
в) $2a_{n} = a_{n-1} + a_{n+1}$
г) $a_{n} = a_{n-1} + a_{n+1}$

## Т8. *(Первый член)*

Какая формула позволяет найти первый член арифметической прогрессии, если известны $a_{n}$, $n$ и $d$?

а) $a_{1} = a_{n} + (n - 1)d$
б) $a_{1} = a_{n} - (n - 1)d$
в) $a_{1} = a_{n} - nd$
г) $a_{1} = \frac{a_{n} - d}{n - 1}$

## Т9. *(Номер члена)*

Выберите все верные утверждения о номере члена арифметической прогрессии.

а) Номер члена должен быть натуральным числом
б) В формуле $n$-го члена используется выражение $n - 1$
в) Если при решении получилось $n = 12{,}5$, то это номер члена прогрессии
г) Для второго члена справедлива формула $a_{2} = a_{1} + d$

## Т10. *(Средний член)*

Для каких значений индекса применимо характеристическое свойство $a_{n} = \frac{a_{n-1} + a_{n+1}}{2}$?

а) Только при $n = 1$
б) При $n \geq 2$, когда существуют предыдущий и последующий члены
в) При любом действительном $n$
г) Только для последнего члена конечной прогрессии
