# Тест по теории. Занятие 9. Свойства функции

**Заданий:** 10  
**Формат:** 4 варианта ответа (а–г). Верных может быть один или несколько. Если в условии сказано «Выберите все верные ответы» — отметьте все подходящие; иначе верный один.

Тест проверяет определения, формулы и правила теории этого занятия.

## Т1. *(Определение нуля)*

Какое значение аргумента называют нулём функции $y=f(x)$?

а) Значение $x$, при котором $f(x)=1$
б) Значение $x$, при котором $f(x)=0$
в) Значение функции $y=0$ при любом $x$
г) Точку пересечения графика с осью ординат

## Т2. *(Нули на графике)*

Как на графике функции находят её нули?

а) По ординатам точек пересечения графика с осью $x$
б) По абсциссам точек пересечения графика с осью $x$
в) По абсциссам точек пересечения графика с осью $y$
г) По значениям функции в начале координат

## Т3. *(Формула нуля)*

Выберите все верные записи, связанные с нулём функции $y=f(x)$. Выберите все верные ответы.

а) $f(x_{0})=0$
б) Нули функции находят решением уравнения $f(x)=0$
в) Для нуля функции всегда выполняется $x_{0}=0$
г) Нулём функции является значение $y=0$, а не значение $x$

## Т4. *(Знак функции)*

Что означает условие $f(x)>0$?

а) Функция принимает отрицательные значения
б) Функция принимает только нулевые значения
в) Функция принимает положительные значения
г) Аргумент функции является положительным

## Т5. *(Промежутки знакопостоянства)*

Что называют промежутком знакопостоянства функции?

а) Промежуток, на котором функция принимает значения только одного знака
б) Промежуток, на котором функция принимает только нулевые значения
в) Промежуток, содержащий все нули функции
г) Промежуток, на котором аргумент не изменяется

## Т6. *(Исключение нулей)*

Выберите все верные утверждения о промежутках, на которых функция положительна или отрицательна. Выберите все верные ответы.

а) В точках нулей функция не является положительной
б) В точках нулей функция не является отрицательной
в) Нули функции входят в промежутки, где $f(x)>0$
г) Нули функции входят в промежутки, где $f(x)<0$

## Т7. *(Определение возрастания)*

Какое условие выполняется для возрастающей функции на некотором промежутке?

а) При $x_{2}>x_{1}$ выполняется $f(x_{2})<f(x_{1})$
б) При $x_{2}>x_{1}$ выполняется $f(x_{2})=f(x_{1})$
в) При $x_{2}>x_{1}$ выполняется $f(x_{2})>f(x_{1})$
г) При $x_{2}<x_{1}$ выполняется $f(x_{2})>f(x_{1})$

## Т8. *(Определение убывания)*

Какое условие выполняется для убывающей функции на некотором промежутке?

а) При $x_{2}>x_{1}$ выполняется $f(x_{2})<f(x_{1})$
б) При $x_{2}>x_{1}$ выполняется $f(x_{2})>f(x_{1})$
в) При $x_{2}>x_{1}$ выполняется $f(x_{2})=f(x_{1})$
г) При $x_{2}<x_{1}$ выполняется $f(x_{2})<f(x_{1})$

## Т9. *(Линейная функция)*

Выберите все верные утверждения о линейной функции $h(x)=kx+b$ при $D(h)=\mathbb{R}$. Выберите все верные ответы.

а) При $k>0$ функция возрастает
б) При $k<0$ функция убывает
в) Коэффициент $b$ определяет, возрастает функция или убывает
г) При $k=0$ функция является возрастающей

## Т10. *(Доказательство монотонности)*

Какая формула используется при доказательстве монотонности линейной функции $h(x)=kx+b$?

а) $h(x_{2})-h(x_{1})=k(x_{2}-x_{1})$
б) $h(x_{2})-h(x_{1})=b(x_{2}-x_{1})$
в) $h(x_{2})+h(x_{1})=k(x_{2}-x_{1})$
г) $h(x_{2})-h(x_{1})=k(x_{2}+x_{1})+b$
