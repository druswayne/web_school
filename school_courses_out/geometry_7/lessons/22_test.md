# Тест по теории. Занятие 22. Сумма углов треугольника

**Заданий:** 10  
**Формат:** 4 варианта ответа (а–г). Верных может быть один или несколько. Если в условии сказано «Выберите все верные ответы» — отметьте все подходящие; иначе верный один.

Тест проверяет определения, формулы и правила теории этого занятия.

## Т1. *(Сумма углов треугольника)*

Какая формула выражает теорему о сумме углов треугольника?

а) $\angle A + \angle B + \angle C = 90^{\circ}$
б) $\angle A + \angle B + \angle C = 180^{\circ}$
в) $\angle A + \angle B + \angle C = 360^{\circ}$
г) $\angle A + \angle B + \angle C = 270^{\circ}$

## Т2. *(Равносторонний треугольник)*

а) Все его стороны равны.

в) Каждый его угол равен $60^{\circ}$.
г) У него обязательно один прямой угол.

## Т3. *(Прямоугольный треугольник)*

## Т4. *(Катеты и гипотенуза)*

## Т5. *(Высота к гипотенузе)*

## Т6. *(Биссектриса)*

## Т7. *(Угол между биссектрисами)*

Биссектрисы углов $A$ и $C$ треугольника $ABC$ пересекаются в точке $O$. Какая формула верна для угла $AOC$, если $\angle B = \beta$?

б) $\angle AOC = 90^{\circ} + \frac{\beta}{2}$
в) $\angle AOC = 180^{\circ} - \frac{\beta}{2}$
г) $\angle AOC = \frac{\beta}{2}$

## Т8. *(Медиана к гипотенузе)*

б) $CM = \frac{1}{2}AB$.

## Т10. *(Внешний угол)*
