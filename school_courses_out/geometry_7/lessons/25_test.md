# Тест по теории. Занятие 25. Неравенство треугольника

**Заданий:** 10  
**Формат:** 4 варианта ответа (а–г). Верных может быть один или несколько. Если в условии сказано «Выберите все верные ответы» — отметьте все подходящие; иначе верный один.

Тест проверяет определения, формулы и правила теории этого занятия.

## Т1. *(Неравенство треугольника)*

Как формулируется неравенство треугольника?

а) Любая сторона треугольника больше суммы двух других сторон.
б) Любая сторона треугольника меньше суммы двух других сторон.
в) Любая сторона треугольника равна сумме двух других сторон.
г) Любая сторона треугольника меньше или равна сумме двух других сторон.

## Т2. *(Условия существования)*

Выберите все верные ответы. Какие условия необходимо выполнять сторонам $a$, $b$ и $c$ существующего треугольника?

а) $a < b + c$
б) $b < a + c$
в) $c < a + b$
г) $a \leq b + c$

## Т3. *(Диапазон третьей стороны)*

Какой формулой задаётся допустимый диапазон длины $a$ третьей стороны треугольника, если длины двух других сторон равны $b$ и $c$?

а) $b + c < a < \lvert b - cvert$
б) $\lvert b - cvert \leq a \leq b + c$
в) $\lvert b - cvert < a < b + c$
г) $b - c < a \leq b + c$

## Т4. *(Проверка наибольшей стороны)*

Какое правило позволяет проверить существование треугольника по трём данным длинам?

а) Нужно сравнить наименьшую сторону с суммой двух остальных.
б) Нужно сравнить любую выбранную сторону с разностью двух остальных.
в) Достаточно сравнить наибольшую сторону с суммой двух меньших.
г) Нужно проверить только равенство всех трёх сторон.

## Т5. *(Вырожденный случай)*

Что означает равенство $AB = AC + BC$ для трёх точек $A$, $B$ и $C$?

а) Точки образуют настоящий треугольник, причём угол $C$ прямой.
б) Точки лежат на одной прямой, а $C$ находится между $A$ и $B$.
в) Точки лежат на одной прямой, а $A$ находится между $B$ и $C$.
г) Точки образуют равнобедренный треугольник.

## Т6. *(Незамкнутая ломаная)*

Выберите все верные ответы. Для незамкнутой ломаной $ABCDE$ справедливы утверждения:

а) $AE < AB + BC + CD + DE$
б) Длина ломаной равна $AB + BC + CD + DE$.
в) $AE = AB + BC + CD + DE$ для любой незамкнутой ломаной.
г) Отрезок, соединяющий концы ломаной, короче длины ломаной.

## Т7. *(Связь стороны с другими)*

Выберите все верные ответы. Из неравенств треугольника следуют утверждения:

а) Любая сторона больше разности двух других сторон.
б) Любая сторона меньше суммы двух других сторон.
в) Нижняя граница допустимого значения третьей стороны включается в диапазон.
г) Верхняя граница допустимого значения третьей стороны не включается в диапазон.

## Т8. *(Периметр внутреннего треугольника)*

Пусть точка $M$ находится внутри треугольника $ABC$. Как соотносятся периметры треугольников $AMC$ и $ABC$?

а) $P(AMC) > P(ABC)$
б) $P(AMC) = P(ABC)$
в) $P(AMC) < P(ABC)$
г) Сравнить периметры невозможно без знания площадей.

## Т9. *(Медиана)*

Какое неравенство справедливо для медианы $BM$ треугольника $ABC$?

а) $BM < \frac{1}{2}(AB + BC)$
б) $BM > \frac{1}{2}(AB + BC)$
в) $BM = AB + BC$
г) $BM < \frac{1}{2}(AC + BC)$

## Т10. *(Свойство медианы)*

Выберите все верные ответы. Какие утверждения характеризуют медиану $BM$ треугольника $ABC$?

а) Точка $M$ является серединой стороны $AC$.
б) Равенство $AM = MC$ обязательно выполняется.
в) Медиана обязательно перпендикулярна стороне $AC$.
г) Медиана соединяет вершину треугольника с серединой противоположной стороны.
