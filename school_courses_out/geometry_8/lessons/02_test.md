# Тест по теории. Занятие 2. Параллелограмм и его свойства

**Заданий:** 10  
**Формат:** 4 варианта ответа (а–г). Верных может быть один или несколько. Если в условии сказано «Выберите все верные ответы» — отметьте все подходящие; иначе верный один.

Тест проверяет определения, формулы и правила теории этого занятия.

## Т1. *(Определение параллелограмма)*

Какое утверждение является определением параллелограмма?

а) Четырёхугольник, у которого все стороны равны

в) Четырёхугольник, у которого диагонали перпендикулярны
г) Четырёхугольник, у которого все углы прямые

## Т2. *(Параллельность сторон)*

Выберите все верные ответы. Для параллелограмма $ABCD$ верны равенства параллельности:

а) $AB \parallel CD$
б) $AD \parallel BC$
в) $AB \parallel BC$
г) $AC \parallel BD$

## Т3. *(Равенство сторон)*

Какие равенства сторон выполняются в параллелограмме $ABCD$?

а) $AB = BC$ и $CD = DA$
б) $AB = CD$ и $AD = BC$
в) $AB = AD$ и $BC = CD$
г) $AB = AC$ и $BD = CD$

## Т4. *(Углы параллелограмма)*

Выберите все верные ответы. Для углов параллелограмма $ABCD$ справедливо:

а) $\angle A = \angle C$
б) $\angle B = \angle D$
в) $\angle A + \angle B = 180^\circ$
г) $\angle A + \angle C = 180^\circ$

## Т5. *(Высота параллелограмма)*

Какое утверждение правильно определяет высоту параллелограмма?

а) Любой отрезок, соединяющий две вершины параллелограмма
б) Перпендикуляр между прямыми, содержащими противоположные стороны параллелограмма
в) Отрезок, соединяющий середины соседних сторон
г) Любая наклонная, проведённая из вершины к противоположной стороне

## Т6. *(Диагонали)*

Выберите все верные ответы о диагоналях параллелограмма.

а) Диагонали пересекаются и точкой пересечения делятся пополам
б) Каждая диагональ делит параллелограмм на два равных треугольника
в) Диагонали всегда равны
г) Диагонали всегда перпендикулярны

## Т7. *(Периметр)*

а) $P = a + b$

в) $P = ab$
г) $P = 2a + b$

а) $AB = AC$
